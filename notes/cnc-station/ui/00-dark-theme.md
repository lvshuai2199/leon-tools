# 00 · 深色主题（备选主题；默认是浅色）

> **主题决定（2026-10-01，取代 D30）**：默认**浅色**（`00-global.md` 和所有标注稿），深色是备选，原型页面加 `?theme=dark` 切换。
> 本文件只管**颜色**。尺寸、间距、字号、布局、点击区全部沿用 `00-global.md` 和各页规格，不重做。
> 做法：所有页面的颜色都已改为 CSS 变量（`src/common.css` 的 `:root` 是浅色值；改成变量后重新截图，18 张逐像素比对完全一致）。之后为了浅色对比度微调过 5 个值（辅助文字、红色文字、蓝底副文字、开关轨道、首页箭头，见 `00-global.md` §1）。深色 = 用下面这段变量覆盖 `:root`。
> 取值原则：尽量贴近现有 /cnc/ 原型的深色（底 #0F1419、顶栏 #141A21、卡片 #1A222B、正文 #E6EDF3、辅助 #8B98A5、边 #36424F、分隔 #2A3541、成功底 #0F3A24），只在对比度不够的地方调整。目标设备 8.8–10" 平板、车间环境：正文 ≥4.5:1，大字（≥24px，或 ≥18.66px 粗体）/ 图标 / 控件轮廓 ≥3:1。

## 2. 可直接粘贴的 CSS 变量块

默认主题是浅色：`:root` 放浅色值（见 `src/common.css`），深色放在 `:root[data-theme="dark"]` 里，变量名相同。切到深色只需给 `<html>` 加 `data-theme="dark"`，并加载这段 CSS（或者直接合进同一个文件）。

```css
/* 深色主题（备选；默认是浅色）：只覆盖 common.css 中 :root 的颜色变量，尺寸/间距/字号一律不动 */
:root[data-theme="dark"]{
  /* 底色与面 */
  --bg:#0F1419; --surface:#1A222B; --chrome:#141A21; --raised:#222C37; --input-bg:#11171D; --fill:#232D38;
  /* 文字 */
  --t1:#E6EDF3; --t2:#B4C0CC; --t3:#95A2AF; --ph:#7D8996;
  /* 线 */
  --border:#3D4A58; --divider:#2A3541; --line-strong:#5A6773; --grid-dot:#2A3541;
  /* 主色：填充与文字分开（#2563EB 做底+白字；#60A5FA 做文字/指示条/选中框） */
  --primary:#2563EB; --primary-hover:#1D4ED8; --primary-pressed:#1E40AF;
  --primary-text:#60A5FA; --primary-bg:#1B2D4A; --primary-bd:#2F5AA8; --info-text:#93C5FD;
  --on-fill:#FFFFFF; --on-primary-sub:#F1F5FF;
  /* 语义色：fill = 圆点/按钮底，-text = 文字，-bg = 浅底 */
  --danger:#DC2626; --danger-text:#F87171; --danger-bg:#3A1D22; --danger-bd:#7F1D1D;
  --success:#22C55E; --success-text:#4ADE80; --success-bg:#0F3A24; --success-bd:#166534;
  --warning:#F59E0B; --warning-text:#FBBF24; --warning-bg:#3A2E0B; --dot-warn:#F59E0B;
  /* 控件 */
  --switch-off:#63707D; --thumb:#E6EDF3;
  --video-edge:#3D4A58; /* 视频窗 #000 在深色卡片上只有 1.31:1，加 1px 描边分出边界；--video-bg 不覆盖，固定 #000 */
  --dis-bg:#1C232C; --dis-bd:#2A3541; --dis-text:#6B7784;
  --focus:#60A5FA;
  /* 遮罩与阴影（深色下阴影几乎不可见，靠 --raised 提亮 + 1px 边分层） */
  --scrim:rgba(0,0,0,.60); --scrim-light:rgba(0,0,0,.35);
  --shadow-pop:0 0 0 1px #3D4A58,0 12px 32px rgba(0,0,0,.55);
  --shadow-drawer:-1px 0 0 #3D4A58,-12px 0 32px rgba(0,0,0,.50);
  --shadow-thumb:0 1px 3px rgba(0,0,0,.6);
  color-scheme:dark;
}
```

原型里在用这套变量的方式：`src/common.css` 定义全部变量（浅色值），`src/theme-dark.css` 就是上面这段；页面地址加 `?theme=dark`，`shell.js` 会追加加载 `theme-dark.css`，并给 `<html>` 设 `data-theme="dark"`；选择器是 `:root[data-theme="dark"]`，所以不带参数时一定是浅色。

**颜色使用规则（深色下必须遵守）**
1. 主色分两个变量：**做底色**（上面放白字）用 `--primary`；**做文字、细线、选中框、指示条**用 `--primary-text`。`#2563EB` 当文字放在深底上只有 3.1:1。
2. 红、绿、黄同理：圆点和实心底用 `--danger` / `--success` / `--warning`，文字用 `--danger-text` / `--success-text` / `--warning-text`。
3. 深色下“更高的层”要“更亮”：bg #0F1419 < chrome #141A21 < surface #1A222B < raised #222C37 ≈ fill #232D38。输入框反过来用更暗的 #11171D，做成凹槽。
4. 深色下不要靠阴影分层，要靠亮度差 + 1px 边。

## 4. 深色下不太理想的地方（已处理 / 需留意）

1. **主色、语义色都得拆成“填充 / 文字”两个值。** 已新增 `--primary-text`、`--danger-text`、`--success-text`、`--warning-text`，所有 `color:` 的写法都已换成这几个变量；浅色主题下它们和原来的值相同，截图不变。开发要照这个规则写，否则深色下蓝色和红色的文字会不达标。
2. **主色块对卡片只有 3.11:1**（开关开、当前料盘格、蓝点），刚好过线。所以细线、选中框一律用更亮的 `--primary-text`，**不要在深色下用 #2563EB 画 1px 线**。
3. **边框和分隔线偏弱**：输入框边对输入框底 1.99:1，卡片边 1.48:1。浅色下只有 1.33 / 1.08，所以深色反而更清楚；输入框另有更暗的底色可以辨认。如果现场试用觉得输入框不好找，把 `--border` 提到 #4A5868（2.48:1）就行，不影响别的。
4. **阴影在深色下几乎无效。** 弹层和抽屉改为“提亮底色 + 1px 描边”，遮罩加浓到 60%。
5. **同色底上的标签会失去“胶囊”外形**：比如报警消息行（红浅底）里的「报警」红标签，文字 5.51:1 照样可读，只是标签和背景的边界不明显。可以接受；想加强的话给 `.msg.alarm .tag` 加 1px `--danger-bd` 边。
6. **禁用态 3.47:1** 故意压暗：禁用的「开始」、设置页不可选的「上位机做主站直连 PLC」（D33）。标题看得清，但明显是灰的；旁边的「第二阶段」标签是 7.98:1。
7. **`--on-primary-sub` 原值在蓝底上只有 4.12:1**，两套主题都改为 #F1F5FF（4.74）。另外“中断”步骤（红底）的副文字原来也用这个颜色，红底上只有 3.85，现在两个主题都改成白字（`.stp.cur.halt small`），浅色的首页报警态截图（1024×640）因此有细微变化。04 夹爪“已跳过”序号由 `--ph` 改为 `--t3`，浅色 04 截图也有细微变化。
8. **视频窗**：底色 #000 两套主题都固定。在深色卡片上 #000 只和底色差 1.31:1，所以深色下加 1px `--video-edge`（#3D4A58）描边分出边界，浅色下不描边。
9. **标注层（`anno.js` 的红色尺寸标注）是按浅底设计的**，本次只出了深色**干净图**，没做深色标注图。
10. **强光下的饱和色**：红和绿的文字用了偏亮的浅色版（#F87171、#4ADE80），实心的红色停止键和报警块保持 #DC2626，面积大，醒目不刺眼。建议到现场亮度下再看一眼。
