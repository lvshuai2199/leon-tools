## 2. 页头（64）
标题「设置」→ 弹性空白 → 全局状态胶囊（1024 隐藏）→ [保存]（主 48，最右）。
- [保存] 只管本页需要手动保存的字段（主站参数、机器人与运行等）；**信号控制端改了自动保存，不需要点保存**。没有手动字段被改动时 [保存] 禁用。
- 有未保存修改时标题旁「● 未保存」，切子页/离开拦截。

## 4. 通讯子页（出图）
### 4.1 信号控制端卡
- 标题行：「信号控制端」18/600 + 蓝标签「自动保存」+ 弹性空白 + 保存反馈「✓ 已自动保存 05:01:36」14 绿（刚改完时出现，并弹 toast「已自动保存」，X-04）。
- 两张单选卡（纵向，间距 8），每张最小 **72 高**，圆角 8，内边距 10/16：
  - 左侧单选圈 24（点击区 48×48）+ 文字区：第一行名称 16/600 + 标签；第二行说明 14 灰。
  - **机械臂端**（选中）：2px 主色边 + #EFF4FF 底；标签「默认」；说明「PLC 接到机械臂控制柜，由机械臂程序读写信号；本机只读显示。」
  - **上位机做主站直连 PLC**（不可选）：#F5F7FA 底 + 1px **虚线**边，名称 #A8ABB2，橙标签「第二阶段」；说明「本期不可选。选用后门、卡盘等安全联锁仍建议留在 PLC 或机械臂端。」**点它不会切换**，只弹提示「第二阶段功能，本期不可选」。

### 4.2 主站连接参数卡（预留）

## 5. 其他子页（同一套栅格，不另出图）
- **可选功能**：表格 3 列「功能名称 | 功能作用 | 是否开启」，行 56 高（开关要 48 点击区），开关放最后一列。行：**翻转台 / 二次定位**（拆两行，各一个开关，X-02、D18）/ 点位组功能（子项「配置/变量组合」在行详情里）。（D35）关掉某功能后，工程编辑页对应节点和节点屏蔽开关变灰并注明「已在设置中关闭」。
- **机器人与运行**：卡片表单两列：ARCS IP、适配器（下拉）、默认速度（后缀 %，10% 一档）、状态采集周期（ms）、心跳超时（ms）。**没有碰撞等级**。
- **高级**：点位组功能、配置/变量组合、变量表（原「数据管理·变量」，表格：变量名 | 类型 | 当前值 | 说明，48 行高）。只有工程师可见。
- **用户与权限**：当前角色、切换到工程师（密码弹窗）、修改工程师密码、无操作 N 分钟自动回到操作员（输入框，后缀 分钟）。
