# 00 通用规范（7 个页面共用）

> 适用：CNC 上下料控制台，8.8–10 英寸触摸平板，只做横屏。设计基准 **1280×800**（CSS px），最小兼容 **1024×640**。
> 依据：plan-v2 §7、§7.8、§8，decisions D1–D31，qa-checklist-v2（P1 项）。所有 px 均为 CSS px。
> 标注稿里的红色数字是按真实布局测出来的尺寸（宽/高/间距），白底红字是字号/字重（如 `20px/600`）。`clean/` 目录下是同一画面不带标注的版本。
> 断点：视口宽 **≤1100** 按 1024 方案排（下文简称「1024」），否则按 1280 方案排。

## 1. 颜色（沿用团队主题 · 默认浅色）

| 用途 | 色值 | 说明 |
|---|---|---|
| 主色 | #2563EB | 主按钮、选中态、链接、当前模块高亮 |
| 主色浅底 | #EFF4FF | 菜单选中底、信息横幅底（D36 已接受；深色备选主题另取对应色） |
| 危险 | #DC2626 填充 / #C81E1E 文字 / 浅底 #FEF2F2 | **只用于**停止、删除、报警、输入错误（红字用 #C81E1E，在浅红底上也 ≥4.5:1） |
| 成功 | #15803D 文字 / #DCFCE7 底 | 运行中、在线、已完成、TRUE |
| 警告 | #B45309 文字 / #FEF3C7 底 | 暂停、等待、未保存、需重新生成 |
| 文字 | #1F2329 主 / #4B5563 次 / #646B78 辅助 | |
| 占位符 | #A8ABB2 | 也用作禁用文字 |
| 边框 / 分割线 | #DCDFE6 / #EBEEF5 | |
| 页面底 | #F5F7FA | 卡片为 #FFFFFF |
| 视频底 | #000000 | 首页监控小窗 / 浮窗 / 全屏层，两套主题都固定 |

- 圆角：4（标签）/ 8（按钮、输入框、小块）/ 12（卡片、弹层）。
- 间距只用 4 / 8 / 12 / 16 / 24 / 32。页面左右内边距 1280 为 24，1024 为 16；卡片间距 1280 为 16，1024 为 12。
- **主题（2026-10-01 用户新决定，取代 D30）**：**默认浅色**（即本表），深色为备选。所有颜色都走 CSS 变量，两套主题尺寸、字号完全相同，切换只换变量块。深色色值和对比度见 `00-dark-theme.md`；原型页面加 `?theme=dark` 可切到深色。
- 浅色微调（为了对比度，只改颜色，不动尺寸）：辅助文字 #6B7280 → **#646B78**（在浅红、浅黄、浅蓝底上也 ≥4.5:1）；红色文字单独用 **#C81E1E**；蓝底上的副文字 #DBE6FD → **#F1F5FF**；首页模块间箭头改用辅助文字色；开关关闭轨道 #C9CDD4 → **#868C98**（原来对白底只有 1.59:1）。
- **颜色写法规则**：主色、红、绿、黄都分“填充”和“文字”两个变量。做底色用 `--primary` / `--danger` / `--success` / `--warning`；做文字或细线用 `--primary-text` / `--danger-text` / `--success-text` / `--warning-text`。浅色下两者同值，深色下不同。

## 2. 字体与字号

- 字体：Noto Sans CJK SC（思源黑体）→ PingFang SC → 微软雅黑。数字一律用等宽数字（`font-variant-numeric: tabular-nums`）。
- 字号表：

| 级别 | 字号/字重 | 用在 |
|---|---|---|
| 页面标题 | 20 / 600 | 页头标题；首页程序名 |
| 状态数值 | 20–24 / 600 | 首页机械臂状态 20、速度 20、数据卡片数字 24、速度步进值 24 |
| 卡片标题 | 18 / 600 | 卡片标题、弹层标题 |
| 小节标题 | 16 / 600 | 卡片内分组标题、模块节点名 |
| 正文 | 16 / 400 | 输入框值、表格单元格、列表、按钮（按钮 500） |
| 标签 | **14** / 400 | 字段名、说明、时间、单位、状态标签。**最小 14，不出现 12 及以下**（标注层的 12px 红字不属于界面） |

## 3. 外壳

### 3.1 左侧菜单（全部页面）
- 1280：宽 **88**，通高。自上而下：Logo 区 64 高（40×40 蓝色方块）→ 7 个菜单项，每项 **88×64**（图标 24 在上，间距 2，文字 14 在下）→ 弹性空白 → 底部「当前角色」64 高（图标 + 「工程师/操作员」）。
- 7 项顺序固定：**首页 / 工程编辑 / 程序 / 信号 / 夹爪 / 料盘 / 设置**。没有 PO、数据管理。
- 选中态：底色 #EFF4FF，图标和文字 #2563EB、600，左侧 3 宽蓝条（上下各缩 12，右侧圆角 3）。未选中：#4B5563。**不用橙色**。
- 1024：宽 **64**，每项 64×64 只有图标；底部角色也只剩图标。64+7×64+64 = 576 ≤ 640，不滚动。
- 菜单右侧 1px #EBEEF5 分割线（用内阴影画，不占宽度）。
- 当前角色点开：切换操作员/工程师（切到工程师需输入密码，弹窗）。

### 3.2 页头（除首页外的 6 页）
- 高 **64**，白底，下边 1px #EBEEF5，左右内边距 24（1024：16），元素间距 16。
- 左：页面标题 20/600；有未保存修改时标题右侧出现「● 未保存」（8px 橙点 + 14px #B45309 文字）。
- 中：本页特有控件（下拉、分段、下发状态等），见各页。
- 右：全局状态胶囊（48 高，「● 运行中 / 待机 / 暂停 / 报警 / 离线」，点开跳首页；1024 下隐藏；工程编辑页不放，位置让给下发状态）+ 本页操作按钮。编辑页的 **[保存] 固定在最右**，主按钮 48 高。
- 页头按钮用 48 高（最小值），是为了和首页 64 高状态条对齐；页面内部的常用操作用 56。
- 首页不用页头，用 64 高状态条（见 01-home.md）。
- 原 /cnc/ 的底部 36 高状态栏、ProcessOn 的底部「程序状态信息 + 运行速度滑块」**不再保留**：状态由页头胶囊代替，速度只在首页调（D31）。

### 3.3 二级 Tab（程序、信号、料盘）
- 紧贴页头下方，高 **48**，白底，下边 1px 分割线。每个 Tab 左右内边距 20，文字 16；选中 #2563EB 600 + 底部 3 高蓝条（左右各缩 16）。

## 5. 交互通则（§7.8、§8）
- 所有可点元素 ≥48 高（48×48），常用操作 ≥56；首页开始/暂停/停止 64。
- **不用悬停**：说明、提示一律「点开显示」（点 ⓘ 或点文字，弹层/抽屉）。
- 编辑页右上角固定一个 [保存]，未保存时标题旁显示「● 未保存」，离开页面（点菜单、切 Tab、切对象）弹确认「有未保存的修改，是否离开？」[留下][不保存离开]。**例外：设置 › 通讯 › 信号控制端，改了自动保存。**
- 运行中（机械臂状态 = 运行/暂停）：所有会动机器人或改下发内容的入口禁用，并在按钮下方或页面顶部写「运行中不可修改」。
- 权限两级：操作员 / 工程师（D29）。工程师专属入口（示教、手动测试、测试写入、记录当前位置）**操作员直接看不到**，不是灰掉。
- 界面上不出现开发术语（loadProgram、Int16Reg、30001、pyaubo-sdk 等）。全站用「松夹爪」，不出现「送夹爪」。
- 碰撞等级只出现在：首页状态条（只读标签）+ 工程编辑的模块属性/工程配置（可填）。设置页、夹爪页都没有。**取值严格 1–9，0 不可选**（见 02-project.md）。

## 6. 校验结果（本稿自检）
每张图都用无头 Chromium 按精确视口渲染后自动检查：文档无横向/竖向溢出、没有元素超出右边界、所有按钮/输入/分段/开关/Tab/菜单/可点胶囊/表格行 ≥48 高。结果见 `src/check-report.json`。首页在 1280×800 和 1024×640 下内部也没有任何滚动容器。
