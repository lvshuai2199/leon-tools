### 13.3 必须改（开发）
1. **D65 被拦以后，看不到是哪个框、为什么红。**
   - 1024 下「料盘进入信号」在第一屏下面（y≈904，屏高 640），点保存后只有底部提示，红框根本看不到。
   - 提示几秒就消失，之后 1280 和 1024 都只剩一个没有说明的红框。
   - 改法：
     - 拦下时把这个框滚到看得见的位置；
     - 在框下面加一行常驻红字「已被「料盘A」占用，换一个信号」：14px、`--danger-text`、行高 20、上间距 2。和夹爪「必填」那行是同一种样式，也是 v4-R1-02d 的画法。
     - 改了信号以后红框和红字一起消失。底部提示可以保留。
2. **1024 下程序菜单打不开。**
   - 1024 的程序列表收成了下拉，没有长按 / ⋯ / 右键可以点；页头只有 [改名] [删除]。所以在最小分辨率下「复制」和「查看引用」都用不了，R0 这一项等于只做了 1280。
   - 改法：在程序下拉右边加一个 48×48 的 ⋯ 次按钮，打开同一个菜单（工程师：改名 / 复制 / 查看引用 / 删除；操作员：查看引用）。
   - 页头的 [改名] [删除] 可以留着，也可以收进这个菜单。
