通用规范见 `00-global.md`。**本页没有碰撞等级**（J-06）。

## 1. 区域总览

| 区域 | 1280×800 | 1024×640 |

| 页头 | 1192×64 | 960×64 |

1280 一屏放下；1024 内容区可纵向滚动（多出约 60，主要是模板卡）。

## 2. 页头（64）
标题「夹爪」→「夹爪数量」14 灰 → **分段控件 [单][双][多]**（192×48，每段 64）→ 弹性空白 → 全局状态胶囊（1024 隐藏）→ [保存]（主，48）。
- 切换数量：单 = 1 张卡（夹爪 A），双 = A、B 两张（J-01），多 = 每行 2 张卡，内容区纵向滚动，卡片顺序 A/B/C/D…。
- 减少数量时若被删的夹爪被程序/模块引用，弹确认「夹爪 C 被 2 处引用，删除后需重新选择」。
- 本期以双夹爪为主；「多」可选但不做特殊布局。

## 3. 夹爪卡（每个夹爪一张，白卡圆角 12，内边距 16，内部间距 12；1024 内边距 12，间距 8）
从上到下：
1. **标题行**：「夹爪 A」18/600 + 实时状态标签（绿「已松开」/「已夹紧」，无反馈信号时灰「无反馈」，超时红「到位超时」）+ 弹性空白 + 文字按钮 [标定 TCP]（工程师，48 高，打开标定向导抽屉）。
2. **TCP 只读块**：#F5F7FA 底圆角 8，3 列 × 2 行，14 字：X / Y / Z / RX / RY / RZ（单位 mm / °）。每个夹爪各自一个 TCP（D10）。
3. 小标题「信号绑定」14/600 #4B5563。
4. **绑定行**（每行 48 高，行间距 8，1024 为 4）：左标签 14（宽 96，1024 为 88）+ 右下拉 48 高通宽。1280 下拉收起时显示完整的「地址 · 信号名」（如「DO 02 · 夹爪A打开」）；点开是完整列表（来自信号页的信号列表，按 DO/DI 过滤）。
   - **1024（已定，10-01）**：下拉收起时**只显示地址**（「DO 02」），**下拉正下方加一行信号名**（「夹爪A打开」）：14 号、次要文字色 `--t2`、行高 20、与下拉左对齐、上间距 2，单行，过长省略号。有这行才接受只显示地址；没有这行的实现不合格。可选项未绑定（「不使用」）或吹气关闭（「未启用」）时不显示这一行。**必填项（打开、关闭）未绑定时（已接受的变体，10-01）**：这一行改为红字「必填」，14 号、`--danger-text`（浅色 **#C81E1E**，不用 #DC2626；深色按 00-dark-theme 用 #F87171）、行高 20、位置与信号名行相同；同时下拉红边，框内显示「必填，请选择」。1280 同样在下拉正下方显示这行红字「必填」。点开的列表仍是完整「地址 · 信号名」。标签在行内顶对齐（与下拉同高 48）。
   - 吹气行的开关放在标签列里（「吹气」+ 开关 56×32，间距 8，1024 为 4），下拉与其他行同宽。
   - 打开（松开）→ DO
   - 关闭（夹紧）→ DO
   - 吹气 → **开关**（56×32）+ DO 下拉；开关关时下拉禁用并显示「未启用」
   - 松开到位 → DI（可选，占位「不使用」）
   - 夹紧到位 → DI（可选）
   - 到位超时 → 输入框，后缀 s
5. 小标题「[锁图标] 手动测试（工程师）」（锁图标是线性 SVG，不是 emoji）。
6. **手动测试按钮**：[打开][关闭][吹气] 三个等宽次按钮 48 高（1280 每个 109 宽）。点后弹确认「将输出 夹爪A 打开，确认机械臂附近无人？」[取消][确认输出]。吹气未启用时 [吹气] 禁用。
   - **运行中三个按钮全部禁用**，小标题右侧显示「运行中不可测试」（J-05）。
   - **操作员看不到**第 5、6 项和 [标定 TCP]（G-12）。
- 选中的卡片 2px 主色边框，右侧模板卡显示这个夹爪的模板；点卡片空白处即选中。

## 4. 动作模板卡（右列）
- 标题「动作模板」18/600 +「被模块和程序引用」14 灰。
- 分段 [夹爪 A][夹爪 B]（通宽 48），与左侧选中卡片联动。
- **取料模板**、**放料模板** 两组，每组一个 1px 边框圆角 8 的列表，步骤行 **48 高**：序号圆 24（#EFF4FF 底主色字）+ 动作名 16 + 右侧参数 14 灰。最后一行文字按钮 [+ 添加步骤]。
- 模板内容按 **D32**（打开 = 松开，关闭 = 夹紧）：
  - 取料：① 吹气 3 s（可选）→ ② 打开（松开）→ ③ 运动到位（取料位）→ ④ 关闭（夹紧）
  - 放料：① 运动到位（放料位）→ ② 打开（松夹爪）
  - D32 里的「等夹紧到位 / 等松开到位（可选）」不单独占一行，做成动作行右侧的参数：绑定了到位反馈 DI 时显示「等松开到位 / 等夹紧到位」，没绑定时显示「不等反馈」（图中夹爪 B 没有夹紧到位信号，所以第 ④ 步是「不等反馈」）。点行可在弹层里切换。
- **吹气开关关闭时**：吹气那一行文字变 #A8ABB2 并加删除线，序号圆变灰，名称后加灰标签「已跳过」，生成的程序里没有这一步（J-04）。
- 点步骤行 → 弹层编辑（动作下拉、参数、等待到位开关）；长按拖动排序。只有工程师能改，操作员只读。

## 5. 1024×640 的变化
- 菜单 64；内边距 16、列间距 12；模板列 296。
- 卡片内边距 12，行距 4，标签宽 88；绑定下拉收起只显示地址，下方 14 次要色一行信号名（见 §3 第 4 条）。
- 内容区允许纵向滚动（加了信号名行后约多出 130px，主要是夹爪卡）。
- 页头隐藏全局状态胶囊。

## 6. 状态
- 未保存：标题旁「● 未保存」，离开拦截。
- 运行中：页头 [保存]、所有下拉、开关、测试按钮禁用；内容区顶部橙色横幅「运行中，只能查看」。
- 信号未绑定：下拉红边 + 14 红字「必填」（打开、关闭为必填）。

3. 「松开到位 / 夹紧到位」拆成两行 DI，v2 写的是「到位反馈（可选）」。
