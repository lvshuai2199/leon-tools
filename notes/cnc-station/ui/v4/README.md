## 7 项菜单里新加的入口（不加菜单项）
- **首页**
  - 显示工程名。
  - 底栏「暂停」的位置在空闲、停止、完成时显示「开始新一批」。
- **工程编辑**
  - 页头工程名 → 工程列表抽屉；新建 → 整屏向导。
  - Tab：流程 | 换产参数 | 版本历史。
- **程序**
  - Tab「点位」：显示「被 N 个程序使用」，记录点位前确认，偏离超过 5 mm 时确认。
  - 「⋯ → 版本历史」。
- **料盘**
  - 点格子看坐标；三点示教；保存时确认计数清零；就绪信号说明。
  - 「⋯ → 版本历史」。
- **信号、夹爪、设置**：不变。设置里的「默认速度」是运行参数（D66）。
