## 1. 改名
程序页的 [改名] 随时可以用。引用按 id 存，改名后工程节点的胶囊、选择区、「调用程序」步骤、删除提示都显示新名字，不标红，也不标黄（改名不算内容改动，版本不 +1，D47 ③ 已确认）。v3-03b 里「初始化」节点的「开机复位 v2」就是改名后的样子（原名「清报警复位」）。

## 2. 删除被引用的程序：先拦，再列出位置
- 程序页步骤区标题行右侧：[改名] [删除]，都是次按钮 48。删除不用红色实心按钮，靠弹窗把关。
- 被引用时点 [删除]：弹窗 560 宽，圆角 12，遮罩盖住整屏（包括导航）。
  - 标题 20/600：⚠「不能删除「主轴吹气」」，右上角 × 48。
  - 正文 16：「被 **3** 处引用。先到这些位置解除引用，才能删除。」
  - 引用列表：每行 56，左边类型标签（工程 / 程序），中间两行（16/500 位置 + 14 #646B78 说明），右边 [去处理 ›] 48。
    - 工程：「上下料一号 · 机床换料」/ 节点调用的模块
    - 工程：「上下料二号 · 主循环 机床换料 之后」/ 插入位
    - 程序：「**回安全点 第 2 步**」/ 调用程序（D46 ② 的写法：程序名 + 第 N 步）
  - 说明 14：「只算直接引用：引用「回安全点」的节点不重复计入」。
  - 底部只有 [知道了]（主按钮 56）。没有「仍然删除」。
- N 只算直接引用（D46 ②），而且要和列表行数一致（M-09）。程序列表第二行「v3 · 3 步 · 引用 3」用的是同一个数。
- [去处理 ›]：工程类跳到工程编辑并选中那个节点或插入位；程序类跳到那个程序并选中那一步。
- 全部解除后，[删除] 弹出普通确认框（「删除「主轴吹气」？删除后不能恢复」[取消] [删除]，删除按钮红色），删除后选择区里也没有了（M-10）。
- 没有改动时页头 [保存] 置灰，版本不 +1（D46 ③），这张图里就是这个状态。

## 3. 料盘删除（D46 ⑤）
和程序一样：被程序的「料盘」步骤或被工程选中时不能删，弹窗列出位置（「上下料一号 · 主循环 选盘」「上料-取毛坯 第 5 步」）。目标是「按选盘规则」的步骤**不算**引用具体料盘，不出现在列表里。弹窗样式和程序删除一样，放在料盘页的 [删除料盘] 上。

## 4. 引用失效（数据损坏、导入）
- 节点：2px #DC2626 边框 + 左侧 4px 红色条；第一行右侧红字「引用的程序不存在」（#C81E1E，浅红底）；失效的那个胶囊显示断链图标 +「引用失效」（红边、红字）。
- 画布顶部红色提示条：「**1 个节点引用的程序不存在**，不能下发，首页不能开始。」
- 页头：1280「下发 ✕ 不能生成：1 处引用失效」，[下发到机器人] 置灰；1024 胶囊「● 引用失效 ›」。
- 属性：红色提示「引用的程序不存在 / 可能是数据损坏或导入造成。重新选择模块，或移除这个引用。」调用列表里那一行红字「引用失效 / 原程序已不存在」；下面放 [重新选择模块]（主按钮，打开选择区，目标就是这个引用）和 [移除]。
- 首页：「开始」禁用，原因「引用的程序不存在」（见 05）。页面不能白屏（M-11）。
- 深色：边框 #DC2626，字 #F87171，底 #3A1D22。

## 5. 程序重名（D46 ④）
- 程序名不能重复，比较前先去掉首尾空格。**保存时检查**，不在输入时打断。
- 1280 和 1024 一样：步骤区顶部的「程序名」输入框（48 高）变红框；末尾的空格用一个虚线小框「空格」（14 #646B78，1px 虚线，圆角 4）显示出来，让人看到为什么重名。下面一行 14 #C81E1E：「已有同名程序「主轴吹气」（首尾空格不算），请换个名字」。
- 步骤列表上方红色提示条 48：「没有保存：程序名重复。改名后再点保存」。左侧列表里这个新程序是红框，第二行写「新建 · 未保存」。
- 保存按钮保持可点（内容有改动），改名后再保存就行。
- 不再用「版本 + 短 id」来区分同名程序（名字已经保证不重复）。
