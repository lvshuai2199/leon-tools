## 主要设计选择
1. **1280：左侧原来的「模块库」列直接改成模块选择区（280），还是三栏**（选择区 / 画布 / 属性），不加第四列，也不用滑出面板。原来的「实现方式」移到属性下拉框里。
2. **1024：不放常驻左列**。点节点打开原来的 360 属性抽屉；点「＋ 调用模块」后，抽屉内容换成选择区（二级页，‹ 返回）。不另开一层，画布不被挤窄，左侧导航一直能点。
3. **引用胶囊 = 名字 + 版本**（24 高，14 字），只用来显示；点整个节点进属性去改，所以不需要 48 的小点按区。
4. **黄色 / 红色节点**：2px 彩色边框 + 左侧 4px 色条 + 文字标签。不靠整块填色，选中时的蓝框和黄、红状态可以同时看出来；深色下也能分清（L-19）。
5. **传递引用**用同一个「程序已更新」，多一行 14px「来自 主轴吹气」（D46 ②）。
6. **锁定主循环**：灰底阶段 + 锁 +「来自料盘设置」，没有拖动把手；6 个插入位，每个 48×48；插入的模块是 48 高胶囊，可以删除。初始化在循环前，收尾在循环后。
7. **首页所有禁用原因用同一种样式**：写在「开始」正下方，14 #C81E1E；详情放在程序卡片的提示条里，并给跳转。料盘取完用蓝色中性提示 + 绿色「完成」，不进报警。
8. 为了给主循环和「＋ 调用模块」腾地方：手动编排的「循环」线移到左侧；画布左下角工具改成两个 48 图标按钮。
