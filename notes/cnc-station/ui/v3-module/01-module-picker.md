## 1. 结论：放在哪里
| 宽度 | 做法 | 为什么 |
|---|---|---|
| 1280 | **原来左侧的「模块库」列（240）改成模块选择区（280）**，不加第四列，也不用滑出面板。仍然是三栏：选择区 280 / 画布 592 / 属性 320 | D38 写的是「左侧加模块选择区」。原模块库里列的「料盘模块 / 料仓 / 单机双爪…」，现在要么是模块（程序、料盘），要么是节点的「实现方式」（移到属性面板的下拉框里），所以左列可以直接换掉。画布 592 放 280 宽节点后，右边还剩 156，够放「＋ 调用模块」按钮。常驻列让工程师边看画布边加，点按次数最少 |
| 1024 | **不放常驻左列**。点节点打开原有的 360 属性抽屉；点节点旁或抽屉里的「＋ 调用模块」后，**抽屉内容换成选择区（二级页，左上角 ‹ 返回属性）** | 960 宽去掉 216 左列和 360 抽屉后，画布只剩 384，节点（248）旁边放不下按钮和循环线。复用同一个抽屉，不另开一层，不会出现「抽屉叠抽屉」。抽屉只在本页内容区，左侧导航一直能点（一点就能回首页按 [停止]） |

## 4. 画布上的节点
- 7 个节点都可以调用模块：初始化、取毛坯、二次定位、机床换料、翻转台、成品下料、**收尾（新，排在最后，D46 ①）**。「收尾」名字后面有 14/600 蓝字「新」，用一个版本后去掉。
- 手动编排时，**收尾只在正常结束后执行**：达到目标件数，或收到结束信号（D47 ⑥）。[停止] 和报警停机直接结束，不执行收尾。所以画布底部的结束标签只写正常结束：「结束（达到目标件数 / 结束信号）」，标注里说明停止和报警不经过收尾。（以前写的是「结束（满产 / 料盘取完 / 停止）」，已改。料盘主循环里「料盘取完 → 做完本圈 → 收尾」写在 04。）
- 一个节点可以调用多个模块，按列表顺序执行；同一个节点里不能重复加同一个模块，已经加过的在选择区显示「已加入」（D47 ② 已确认）。
- 节点 280×64（1024：248×56），圆角 8。第一行：名字 16/600 + 右侧状态标签（24 高）。第二行：**引用胶囊**。
- **引用胶囊** = 名字 + 版本：24 高，圆角 4，14 字，浅灰底 + 1px 边，版本号用 #646B78，例如「主轴吹气 v3」。胶囊只用来显示，不能单独点；点整个节点就进属性面板，在那里改。一行放不下时只显示能放下的部分，完整列表在属性里。
- 没有调用模块时第二行写「未调用模块」14 #646B78（取毛坯、成品下料前面加来源，例如「料框 · 未调用模块」）。
- 选中节点：2px 蓝框 + 蓝浅底；**节点右侧 8 处出现「＋ 调用模块」**（次按钮 48 高）。1280 点它会把焦点放到左侧搜索框，1024 点它打开抽屉里的选择区。
- 手动编排的「循环」虚线从右侧改到**左侧**，把右侧留给「＋ 调用模块」。
- 画布左下角的工具改成两个 48×48 图标按钮（展开步骤、定位到当前），把左下角让给较长的流程。
