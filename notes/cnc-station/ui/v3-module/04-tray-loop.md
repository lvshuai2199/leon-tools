## 1. 什么时候出现
工程选了至少一个料盘，画布就显示锁定的主循环；没选料盘（料框、输送线）时，仍然是 01 里的手动编排（7 个节点）。

### 1.1 从手动切到主循环：先确认（D47 ⑦、D48 ②③⑥）
- 触发（D48 ②）：**每次**工程从「没有料盘」变成「有料盘」都弹（在选择区「料盘」页签点「加入」，或在取毛坯的来源里选「料盘」）。取消全部料盘、改回手动以后再加料盘，也会再弹。工程里已经有料盘，再加第二个料盘时不弹。
- 弹窗按全局「确认弹窗」规则：居中，480 宽，圆角 12，标题 18/600，正文 16，底部按钮 56。遮罩盖住整页。工程编辑页没有 [停止]，所以这里不涉及「不能盖住停止」的规则；1024 时弹窗盖在抽屉上面，抽屉不用先关。
- 标题：「将切换为料盘自动主循环」。
- 正文：「选中「料盘A」后，主循环按料盘设置自动生成并锁定。已有的模块这样处理：」
- 去向列表（1px 边框，圆角 8，每行最小 48，左列 128 写节点 14/600 #4B5563，右列 16 写去向），**按当前工程实际列出**。规则分三种（D48 ③）：
  1. **取毛坯、机床换料、成品下料上的模块** → 移到**同名阶段**后面的插入位，顺序不变。
  2. **其他普通节点（包括二次定位、翻转台，以及手动加的节点）** → **整个节点**移到它**前一个阶段**后面的插入位，排在第 1 条挪过来的模块**前面**。被屏蔽的节点挪过去以后仍然是屏蔽状态。
  3. **只有初始化、收尾不动**（它们本来就在主循环前、后）。
- 示例工程（图 v3-04c）一共 5 行：

  | 左列 | 右列 |
  |---|---|
  | 机床换料上的模块 | 进出机床 v5、主轴吹气 v3 → 移到「机床换料」后面的插入位 |
  | 取毛坯、成品下料 | 没有模块，不用移（有模块时写成「… → 移到「取毛坯」后面的插入位」，成品下料也一样） |
  | 二次定位节点 | 整个节点移到「取毛坯」后面的插入位 |
  | 翻转台节点 | 整个节点移到「机床换料」后面的插入位，排在进出机床、主轴吹气前面 |
  | 初始化、收尾 | 不动 |

  通用写法（给开发）：同名节点行「{节点}上的模块」→「{模块 版本、…} → 移到「{同名阶段}」后面的插入位」；普通节点行「{节点}节点」→「整个节点移到「{前一阶段}」后面的插入位」，如果这个插入位还有挪过来的模块，后面加「，排在{模块名、…}前面」；最后一行「初始化、收尾」→「不动」。**不要再写「…上的模块不动」来概括二次定位、翻转台。**
- 说明 14 #646B78：「点「取消」就不选这个料盘，工程保持手动编排」。
- 按钮：[取消]（次，56，最小宽 120）[切换]（主，56，最小宽 120）。点切换后画布变成锁定主循环，页头出现「未保存」。**保存以后**工程才变成待核对；选「不保存离开」就恢复成切换前的样子，也不变待核对（D48 ⑥）。

## 2. 画布结构（从上到下）
初始化（48 高单行节点，胶囊放在名字右边）→ **主循环框** → 收尾（48，**排在最后**，料盘全部取完后执行，D46 ①）。

主循环框：宽 320，2px #C0C4CC 边，圆角 12，白底，内边距 0/8/8。
- 框头 48：「主循环」16/600 + 灰标签「🔒 来自料盘设置」（28 高，14 #4B5563）+ 右侧 [去料盘页 ›]（1024 隐藏，在抽屉里放）。
- 阶段（**锁定**）：选盘 → 取毛坯 → 机床换料 → 成品下料 → 计数。每个阶段 48 高，灰底 #F5F7FA + 1px 边，图标 20 + 名字 16/600 + 说明 14 #646B78 + 右侧锁 20。**没有拖动把手，长按不能拖，没有删除菜单**（L-05）。点阶段 = 在属性里看只读信息。
- **插入位**：每个阶段前后各一个，一共 6 个，高 48。中间画一根 2px 连线，「＋」按钮 48×48，2px 虚线框，蓝色加号。
  - 插入了模块：模块显示成 48 高的胶囊按钮（图标 + 名字 + 版本，例如「二次定位 v2」），排在「＋」左边。插入的模块就是普通节点，可以点开、删除，可以加入多个，按从左到右的顺序执行。
  - 选中的插入位：「＋」变成实线蓝框 + 蓝浅底 +「插入到这里」，左侧选择区的目标条跟着变成「插入到：机床换料 之后」。
- 「下一圈」：从计数后面画一根虚线回到选盘，放在框的左侧，竖排 14 字「下一圈」。
- 1280 一屏能放下（画布 736 高，用了 720）；1024 画布可以纵向滚动，选中的元素自动滚到可见位置。

## 3. 属性面板
- 选中插入位（1280 图）：「插入位 · 机床换料 之后 / 插入的模块每圈都执行，可删除」+ 已插入模块列表（每行 56，× 48 移除）+「在左侧选择程序模块，点「加入」插到这里」。下面是「🔒 主循环 · 来自料盘设置」只读组：料盘「料盘A、料盘B」[去料盘页 ›]、选盘「默认规则（按优先级）」，还有 3 条规则（D46 ⑥）：
  - 第一圈机床里没有件：跳过成品下料
  - 最后一圈：不再取毛坯，只下料
  - 全部料盘取完：做完本圈 → 收尾 → 首页提示换盘
- 选中锁定阶段（1024 抽屉：取毛坯）：标题前加锁；「来自料盘设置 · 不能删除、不能调整顺序」；只读行（48 高，左标签 14，右值 16，右边跳转链接）：料盘 [去料盘页 ›]、取料顺序「第 1 层起，按格位编号」、夹爪「夹爪A · 取料模板」[去夹爪页 ›]；碰撞等级照常能改。
- **多料盘只用默认规则**（D9 / D44）：按优先级选第一个「就绪且没取完」的料盘。**不画额外条件**（信号比较、变量）的界面。

## 4. 取消全部料盘（L-06）
改成料框或输送线时弹确认框：「改为手动编排？工程不再选料盘，主循环会变回手动编排。已插入的 2 个模块（二次定位、主轴吹气）按原顺序保留为普通节点。改完后工程变成**待核对**，要重新下发核对才能开始。」[取消] [改为手动编排]。
- 确认后（D47 ④）：页头先出现「未保存」；**保存后**（D48 ⑥）下发状态变成「○ 待核对」（1024 胶囊「● 待核对 ›」），样式和 02 一样；首页「开始」禁用，原因「工程待核对」，提示条写「工程已改为手动编排，待核对」（见 05 §4）。选「不保存离开」就恢复原样，不变待核对。

## 5. 程序页新增「料盘」步骤（D41）
- 底部添加栏多一个 [料盘]，一共 6 个：移动 / 信号 / 等待 / 夹爪动作 / 料盘 / 调用程序，每个 56 高，平分宽度；1024 去掉图标只留字。
- 步骤行：标签「料盘」（和其他类型一样是蓝标签，最小宽 72），描述「取料 · 按选盘规则」或「放料 · 料盘A」，右侧补充「料盘点位」或「原格位」。
- 属性：
  - 动作：分段「取料 | 放料」48。
  - 目标：下拉 48，选项「按选盘规则」、料盘A、料盘B（料盘页保存的料盘模块，按 id 引用）。
  - 说明（灰底 14）：选「按选盘规则」时写「按优先级选第一个「就绪且没取完」的料盘。这一步不算引用某个料盘」（D46 ⑤）；选具体料盘的放料时写「放回刚取空的那格。引用了料盘A，料盘A 因此不能删」（D43）。
  - 「引用（只读）」：点位「按料盘计算」[去料盘页 ›]；夹爪「夹爪A · 取料 / 放料」[去夹爪页 ›]；顺序「第 1 层起，按格位编号」或「放回原格位」。**没有点位坐标输入框，也没有 DO 输入**（L-02）。夹爪页改了信号，这里显示的内容跟着变（L-03）。
