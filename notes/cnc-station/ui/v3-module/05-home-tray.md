## 1. 料盘行（D45）
- 位置：程序卡片标题行右侧，在「第 129 次循环」左边。
- 样式：48 高胶囊，圆角 8，浅灰底 + 1px 边。料盘图标 20 + 文字 16：
  - 1280：「**料盘A** · 第2层 · 第5格 · 剩 **25/45**」
  - 1024：「**料盘A** · 剩 **25/45**」+ 右箭头 20，同时隐藏「当前运行程序」和「第 N 次循环」，给它腾地方。
- **「剩 x/y」是整盘的数字**（D47 ①，修正了 D45 的理解）：x = 整盘剩余格数，y = 整盘格数。例子是 3 层 × 15 格 = 45 格的料盘，正在取第 2 层第 5 格：已取 15 + 5 = 20，剩 25/45。新换的盘显示「第1层 · 第1格 · 剩 45/45」（v3-05c）。层和格位在 1280 照常显示，1024 放在弹层里。
- 点击（两种宽度都可以点，1024 主要靠这个）：在胶囊下方 8 处弹出 320 宽的弹层，有指向胶囊的小箭头。行高 40：料盘「料盘A · 优先级 1」/ 层「第 2 层 / 共 3 层」/ 格位「第 5 格 / 每层 15 格」/ 整盘剩余「25 / 45」/ 下一个料盘「料盘B · 就绪」。弹层和浅遮罩都**只盖到底栏上沿**，[停止] 一直能点。点空白处关闭。
- 数字每圈刷新。多料盘时显示当前在用的那个料盘。

## 3. 料盘全部取完（D43）
- 机械臂状态：「✓ 完成」，绿底 #DCFCE7 + #15803D 字。**不是报警**，也不停在「运行中」。
- 4 个阶段都显示「已完成」。「当前步骤」那一行换成**蓝色中性提示条**（不用红色，不进报警）：✓ 图标 28 +「料盘已取完，请换盘」18/600 +「最后一圈已下料，收尾已执行。换盘后计数清零，可重新开始。」14 + 右边 [去料盘页]（次按钮 48）。机床换料子阶段那一行隐藏。
- 料盘行变绿：1280「✓ 料盘A、料盘B 已取完 · 剩 0」，1024「✓ 料盘已取完 · 剩 0」。
- 底栏：「开始」禁用，下方原因「请先换盘」；「暂停」禁用；[停止] 不变。
- 信息提示：第一条是绿色标签「完成」+「料盘已取完，请换盘」，下面是「收尾完成：回安全点」「最后一圈：不再取毛坯，只下料」等。报警数是 0 时只显示灰色「报警 0」。
- 换盘（料盘进入信号，或料盘页「已换盘」）后：计数清零，状态回到「待机」，「开始」恢复可点（L-11）。

## 4. 「开始」禁用并写原因（D39 / D40）
- 原因写在「开始」按钮**正下方**的 16 高原因行：14 #C81E1E（深色 #F87171）。所有禁用原因用同一种样式。
  - 待核对：「工程待核对」
  - 引用失效：「引用的程序不存在」
  - 料盘取完：「请先换盘」
  - 有报警：「有报警未处理」（原来就有）
- 程序卡片里同时用提示条说明详情，并给跳转（这一条换掉「当前步骤」那一行）：
  - 黄：🔄「程序已更新，工程待核对」/「机床换料、收尾 2 个节点引用的程序有新版本，重新下发并核对后才能开始。」[去工程编辑]；程序名后面的标签「待核对」是黄色。
  - 红：断链图标「引用的程序不存在」/「「机床换料」节点引用的程序已不存在，请到工程编辑重新选择。」[去工程编辑]；标签「引用失效」是红色。
- 两种情况同时出现时只显示红色（引用失效优先），修好以后再显示黄色（D47 ⑤ 已确认）。
- 待核对的其他原因用同一套黄色样式，只换说明文字。例如取消全部料盘、改回手动编排后（D47 ④），写「工程已改为手动编排，待核对」/「重新下发并核对后才能开始。」原因行仍然是「工程待核对」。
- 机械臂状态是「待机」，阶段都显示「等待」，数据卡片显示 0 或「—」。
