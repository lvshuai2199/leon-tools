## 5. 右：属性栏（1280 常驻 320；1024 抽屉 360）
### 5.1 结构
- 顶部分段控件（通宽，48 高）：**[模块属性] [工程配置]**，内边距 12/16。
- 下方内容区纵向滚动，内边距 16，组间距 16；每组以 1px 分割线 + 16/600 组标题分开。
- 属性改动立刻写进草稿并点亮「● 未保存」，**不设 [确定] 按钮**（ProcessOn 程序属性面板里的 [确定] 不采用，统一走页头 [保存]）。
- 没选中任何节点时，默认显示「工程配置」。

### 5.2 模块属性（按槽位不同，字段不同）
通用头：模块名 18/600 + 实现名 14 灰（例「单机双爪一次进出 · 机床1」）。

**碰撞等级（每个模块都有，C-01～C-04）**
- 组标题「碰撞等级」16/600 + 「1–9」14 灰。
- 步进输入：[−] 48×48 次按钮 + 数值框 **64×48**（20/600，居中，可点弹数字键盘直接输入）+ [+] 48×48 + 「越大越灵敏」14 灰。
- **取值严格 1–9，任何角色都不能选 0**。到 1 时 [−] 禁用，到 9 时 [+] 禁用。键盘输入 0、10、负数、小数或清空：数值框红边、红字，下方 14 红字「碰撞等级范围 1–9，最小为 1」，此时 [保存] 和生成被拦截（见 1024 图）。不提供灰掉的 0 档。
- 下方文字按钮「ⓘ 如何关闭碰撞检测？」（48 高）：**点一下**展开说明块（#F5F7FA 底，圆角 8，14 字）「如需关闭碰撞检测，请在 Aubo 示教器上操作。」，再点收起。不用悬停。
- **子阶段覆盖**（有子阶段的模块才有，例如机床换料：进机床 / 取成品 / 放毛坯 / 出机床）：说明「子阶段不填则继承模块等级」14 灰；每行 = 子阶段名 14（72 宽）+ 输入框 48 高。未填时框内灰字「继承模块（4）」；填了显示数值 + 框内后缀「覆盖」，并出现清除按钮（点了回到继承）。点输入框弹出同样的 1–9 步进弹层，同样拦截 0。

**其他字段（按槽位）**
- 取毛坯 / 成品下料：来源/去向分段（料盘模块 / 料仓 / 料框 / 输送线）；**料盘模块下拉——只能选料盘页已生成的模块**，不能在这里改料盘参数，下方「参数请到料盘页修改」+ 文字按钮 [去料盘页 ›]（E-04）；使用夹爪/动作模板下拉；**多料盘选择条件**（见 5.3）。
- 机床换料：使用夹爪/动作模板下拉；换料参数组：主轴吹气（开关）、卡盘动作顺序（分段：先取后放 / 先放后取）、卡盘动作后延时（输入框，后缀 s）；调用程序列表（取前/取后吹气子程序等）。
- 初始化：清报警、信号复位、变量复位（开关）、初始点（点位下拉）。
- 二次定位 / 翻转台：启用开关（与工程配置里的节点屏蔽同步）+ 调用程序。

### 5.3 多料盘选择条件（E-08）
- 说明 14 灰：「按优先级，选第一个满足全部条件的料盘；都不满足时提示“无可用料盘”并等待」。
- 条件列表（1px 边框圆角 8 的块），每条 48 高：类型标签（蓝「信号」/蓝「变量」）+ 条件文字（例「料盘进入信号 = 1」「剩余数量 > 0」）；点整行打开编辑弹窗（信号判断：信号下拉 + 比较 = / != / > + 值；变量比较：变量下拉 + 比较 + 值）。
- 最后一行文字按钮 [+ 添加条件]。
- 默认两条（就绪信号 = 1、剩余 > 0）；具体条件还在等用户确认（plan-v2 §12 第 3 条），布局不受影响。
- 料盘的优先级在料盘页设置，这里只引用。

### 5.4 工程配置（`02-project-config-1280x800.png`，E-06）
- 标题「工程配置」18/600 +「对整个工程生效」14 灰。
- 节点屏蔽组：二次定位、翻转台两行，每行 56 高：名称 16/500 + 说明 14 灰 + 右侧开关。关掉后画布节点变「已屏蔽」，生成的程序里没有对应节点（E-05）。
- 碰撞等级组：**空跑默认等级（必填）**，与模块等级同一个步进控件，1–9，同样拦截 0 和空值；为空时生成按钮不可用，原因「空跑默认等级未填」（C-05）。
- 引用汇总（只读）：料盘数量「2 个（料盘A、料盘B）」来自料盘页；夹爪类型「双夹爪」来自夹爪页。每行 56 高，不可编辑，点行可跳到对应页面。

## 6. 1024×640 的变化
- 菜单 64；模块库 216；属性栏变为**右侧抽屉 360 宽**，高度为页头以下全高。
- 点选画布节点自动打开抽屉；抽屉头 56 高：模块名 18/600 + 48×48 关闭；下面仍是 [模块属性][工程配置] 分段。
- **抽屉不加遮罩**，画布仍可操作；抽屉只盖住画布右侧，画布左下角的操作按钮（x296 起）始终露出（E-01）。
- 下发状态收成胶囊；画布说明文字隐藏；节点宽 248。

## 7. 状态
- 空工程：画布只有开始/结束和 4 个空槽位（虚线框「点这里选择取毛坯方式」），属性栏显示工程配置。
- 运行中：页头 [下发到机器人]、[保存] 禁用；画布顶部橙色横幅；属性全部只读。
- 核对未通过：下发状态「核对未通过」橙色，点开看原因。
- 料盘改过：引用它的节点显示「需重新生成」，下发状态回到「生成」前。

## 8. 与 v2 的出入 / 我的理解
1. **碰撞等级 0 档**：按最新决定，任何角色都不能选 0，输入 0 报错，不做灰掉的 0 选项（plan-v2 §3.2、D23 已同步修改）。可点开的帮助文字「如需关闭碰撞检测，请在 Aubo 示教器上操作」已加上。
2. 工程配置区 v2 只说要有，没说放哪。放在属性栏的第二个分段「工程配置」里，没选节点时默认显示。
3. 本页页头不放全局状态胶囊，位置让给下发状态；运行中靠横幅提示。
4. 属性面板不设 [确定]，统一走 [保存]（与 v2 §8「编辑页右上角固定 [保存]」一致，但和 ProcessOn 程序属性面板不同）。
5. 碰撞等级控件用「步进 + 可直接输入」，没用 1–9 九段按钮（320 宽放不下 9×48）。
