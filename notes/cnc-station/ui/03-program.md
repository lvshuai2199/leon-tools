## 2. 页头（64）
1. 标题「程序」+「● 未保存」。
2. **夹爪控制下拉** 220×48：框内前缀「夹爪控制」14 灰 + 值「夹爪A」16。用来选本程序使用的夹爪（D27、R-03），选项来自夹爪页（夹爪A / 夹爪B / 夹爪A+B）。新增「夹爪动作」步骤时默认用这里选的夹爪。
3. 弹性空白 → 全局状态胶囊（1024 隐藏）→ [+ 新建程序]（次，48）→ [保存]（主，48，最右）。
- ProcessOn 里的 [打开] 不单独做按钮：左侧程序列表就是「打开」。

## 3. Tab 条（48）
**步骤 / 点位 / 文本视图（高级）**（R-01）。
- 点位：合并原「数据管理·点位表」和「信号·点位数据」。表格 5 列：点位名 | 所属程序 | 坐标摘要（X/Y/Z）| 更新时间 | 引用次数；行 48 高，点行打开右侧抽屉看完整 6 轴坐标和 [记录当前位置]（工程师）。
- 文本视图（高级）：只读代码视图，工程师可切换为可编辑；等宽字体 14，行号灰色。操作员看不到这个 Tab。

## 4. 左：程序列表（240）
- 白底，内边距 12，条目间距 8。
- 顶部搜索框 48 高（放大镜图标 + 占位「搜索程序」）。
- 条目 **56 高**，圆角 8，内边距 12：名称 16/500 + 说明 14 灰（「6 步 · 被 1 个模块调用」/「未被调用」）。选中：#EFF4FF 底，名称主色 600。
- 点条目切换程序；当前程序有未保存修改时先拦截。长按条目弹菜单：复制 / 重命名 / 删除（删除被调用的程序时提示「被 N 个模块调用，不能删除」）。

## 5. 中：步骤区
- 背景 #F5F7FA。
- 顶部 64 高：程序名 18/600 + 说明 14 灰「6 步 · 按住左侧把手拖动排序」。1024 下程序名换成 **程序下拉 260×48**（「程序 上料-取毛坯」）。
- 步骤列表：左右内边距 16，步骤间距 8（1024：6），可纵向滚动。
- **步骤卡 64 高**（1280 宽 600），白底，1px #EBEEF5，圆角 8：
  - 左侧**拖动把手** 48×62（点击区），六点图标 #A8ABB2。**按住把手才能拖动**，避免滑动列表时误拖。
  - 序号圆 28（#F5F7FA 底，14 字）
  - 类型标签（蓝色信息标签，最小宽 72）：移动 / 信号 / 等待 / 夹爪动作 / 调用程序
  - 描述 16，单行省略
  - 右侧摘要 14 灰（「直线 · 20%」「超时 2 s」「取料模板」）
  - 选中：2px 主色边 + #EFF4FF 底。
  - 点整张卡片选中；长按弹菜单：复制 / 在下方插入 / 删除（删除需确认）。
- **底部添加栏**（固定，白底，上边 1px 分割线，内边距 12/16）：5 个等宽次按钮 **56 高**：[移动] [信号] [等待] [夹爪动作] [调用程序]（每个带 20 图标）。1280 每个 114 宽，1024 每个 115 宽。新步骤插在当前选中步骤下方，并自动选中（R-02；ProcessOn 的第二个「等待」已改为「夹爪动作」）。
- 空程序：列表区中间「还没有步骤，点下方按钮添加」14 灰。

## 6. 右：步骤属性（320，内边距 16，组间距 16）
- 标题「步骤 3 · 移动」18/600 + 说明 14 灰「改动即写入草稿，统一点页头保存」。**不设 [确定]**。
- 字段标签在上（14 灰，间距 6），输入 48 高，单位在框内后缀。

**移动**（1280 图）
- 运动方式：分段 [关节][直线]，通宽。
- 速度 / 加速度：两个输入框并排（后缀 %）。
- 目标点：下拉（本程序点位 + 公共点位）。
- 坐标只读块：#F5F7FA 底圆角 8，3 列 × 2 行，14 字：X / Y / Z / RX / RY / RZ。
- **[记录当前位置]**：主按钮 **56 高通宽**。把机械臂拖到位后点它，写入当前点位（R-04，Mock 下写模拟值），成功后按钮下方出现「已记录 05:02:11」14 绿字。**只有工程师可见**，操作员看不到。
- [按住移动到此点]：次按钮 56 高通宽，**按住才动，松手即停**（工程师可见，运行中禁用）。

**等待**（1024 图）
- 等待方式：分段 [时长][信号]。
- 时长：输入框（后缀 s）。
- 信号：信号下拉 → 条件：分段 [=][!=][>]（每段 64 宽）+ 值输入框 → 超时（后缀 s）→ 超时后：分段 [报警暂停][跳过继续]（R-05）。

**信号**
- 信号类型：分段 [Modbus][IO][工具IO]（ProcessOn 便签「可勾选 modbus、IO、工具IO」，这里改为单选分段）。
- 信号：下拉（按类型过滤）；写入值：分段 [0][1]（数值型为输入框）。

**夹爪动作**
- 夹爪：下拉（默认取页头夹爪控制）；动作：分段 [打开（松开）][关闭（夹紧）][吹气]，或选「引用动作模板」下拉（取料模板 / 放料模板，来自夹爪页）。
- 吹气在夹爪页被关掉时，吹气选项灰掉并注明「夹爪页已关闭吹气」。

**调用程序**
- 程序下拉（本页其他程序，不能选自己）；下方文字按钮 [打开该程序 ›]。

## 7. 1024×640 的变化
- 菜单 64；程序列表隐藏，改为步骤区顶部 260×48 程序下拉。
- 步骤区 640 宽，步骤间距 6；属性栏仍 320 常驻（v2 只要求工程编辑改抽屉，本页两栏放得下）。
- 页头隐藏全局状态胶囊。

## 8. 状态
- 未保存：标题旁「● 未保存」；切程序、切 Tab、点菜单都弹「有未保存的修改，是否离开？」（R-07）。
- 运行中：添加栏、拖动、属性全部禁用，步骤区顶部橙色横幅「运行中，只能查看」；[记录当前位置]、[按住移动到此点] 禁用。
- 操作员：只读，看不到 [记录当前位置]、[按住移动到此点]、文本视图 Tab。

## 9. 与 v2 的出入 / 我的理解
1. ProcessOn 的程序页是空白自由画布，v2 §7.3 定为「纵向步骤列表（可拖动排序）」，按 v2 做。
2. 1024 下程序列表收成下拉（v2 没写 1024 怎么处理）；属性栏保持常驻。
3. 「按住移动到此点」是我加的（示教常用，触屏上用按住防误动）；如不需要可删掉，不影响布局。
4. 等待超时后的处理（报警暂停/跳过继续）是我补的字段，v2 只写了超时。
