# 美工评审：「生成上下料工程 + 后续快速修改」界面流程（10-07）

对象：线上 http://124.220.57.33/cnc/，文件和 dc0fe47 的 `cnc-prototype.fix1004.html` 逐字节一致（sha256 8fed481d…）。
方法：无头浏览器在 1280×800 浅色下用真实点击走产品给的 7 个场景，每个场景都从清空的本地数据开始。数的是点击次数（每输入一个框算 1 次，打字不算）。1024×640 只抽查了插入模块。截图在 `/workspace/cnc-flow-shots/`。
口径：和 产品 `review-1007-product.md`（G1–G6）、开发 `review-1007-program-gen.md` 一致。这里只看界面，不看后端（「下发」在原型里是动画）。
只读评审，没有改任何稿子和原型。

## 结论：部分满足

- **改已有工程的链路是好的**：
  - 改程序、改料盘以后，受影响的节点标黄，工程变成待核对，首页「开始」禁用并写原因（D39 / D46）。
  - 插入或去掉模块只要 3 步。
  - 运行中工程和程序都锁住了。
  - 没保存就离开会拦一下。
- **不满足的有三块**：
  - 不能新建或复制工程（场景 0、6）。
  - 改错了只能在保存前放弃，保存后回不去，也看不到改了什么（G3）。
  - 换规格、改点位这类「快改」各有一处会悄悄出错：输入框丢值、计数不跟着变、共享点位改了别的程序。

## 1. 7 个场景逐个走查

| 5 | 程序升级后工程跟着更新 | **9 次**：程序 → 选程序 → 选步骤 → 改值 → 保存 → 工程编辑 → 下发 → 首页 → 开始 | 流程清楚（D39）。只是黄标只说「程序已更新」，属性里写 v1 → v2，**看不到改了哪一步、哪个值** | 能：标黄、待核对、首页写原因 | 程序回不到上一版；按 D39，工程一定跟最新版 |

另外运行中的保护：工程编辑、程序页都锁住了，有「运行中，只能查看」横幅；料盘规格框是灰的、不能改。但料盘页还能点进「编辑/示教」，进去后显示「编辑中」，「保存」也是亮的，容易误会。

## 2. 主要问题（按影响排序）

**必须（不改，这个需求做不成，或者会悄悄出错）**
1. **只有一个工程**：不能新建、复制、切换（场景 0、6，对应 G1）。
2. **料盘规格输入丢值**（缺陷，归开发）：改完一个框直接点下一个框，下一个框输入的内容会丢。换规格是最常见的快改，丢了值也看不出来。
3. **改行 / 列 / 层以后，计数和示教点不跟着处理**：既不提示「计数清零」，也不提示「P2 / P3 要重新示教」（或者按间距自动算）。**要产品定规则。**
4. **已完成件数不清零，改件数要重新下发**：想再做一批，只能把目标件数往上加再重新下发。**要产品定：**首页要不要加「开始新一批（件数清零）」？目标件数算不算「不用重新下发」的运行参数？
5. **没有历史、看不到改了什么、保存后回不去**（G3）：程序、料盘、工程都只有版本号。
6. **记录点位没有确认，也不显示旧值和新值**；改共享点位会让别的程序一起变版本，却没有告诉用户是哪几个。

**建议**
1. 新料盘的「进入信号」只能选已有信号；同一个信号绑到两个料盘时要提醒。
2. 料盘模式下要写明「取放料按料盘自动生成，不用自己写程序」；插入位里如果放了含「料盘取料」步骤的程序，要提醒会重复取料。
3. 「存在空白配置项」只在必填项为空时弹；可选项为空不打断。
4. 离开拦截加「保存并离开」。
5. 运行中，工程配置的输入框要显示成只读；料盘页的「编辑/示教」要置灰。
6. 点位表每一行能点开：看引用位置、看旧坐标和新坐标、能微调毫米值、能跳到对应步骤。
7. 程序列表加长按菜单「复制 / 改名 / 删除 / 查看引用」（下一轮已排），顺带补上「复制程序」。

## 3. 优化方向（和产品 G1–G5 对应；界面草图另出，见 `/workspace/cnc-ui/v4-draft/`）

| 方向 | 解决的问题 | 和现有决定的关系 |
|---|---|---|
| 工程列表：新建 / 复制 / 切换 / 删除 | 必须 1、场景 6 | 新增。复制后按「从其他料盘新建」的做法追问「对应数据是否已修改」，并把复制出来的工程标成待核对 |
| 新建工程向导 + 模板（双爪单机床 + 料盘） | 场景 0 的 37 次点击、建议 1–2 | 新增。向导最后一步列出缺的东西（信号、示教点），全部补齐才能下发 |
| 换产参数页（只放标 A 的项：料盘行列层和间距、目标件数、工件尺寸等）：改过的值高亮，显示改前 → 改后 | 必须 3、4、6，场景 1–3 | **要产品定**哪些项改了不用重新示教、不用重新下发（和开发 P0-3 配方化一起定）；如果还是要下发，按 D39 走待核对 |
| 版本历史：对比 + 回到某一版 | 必须 5 | **要产品定**：回滚程序以后工程是跟着变（和 D39 一致，标黄）还是可以锁定版本 |
| 工程导出 / 导入（本地 JSON） | 场景 6 的备份、拷到另一台 | 导入走现有的结构校验，导入后待核对 |
| 下一轮 6 项（操作员视角、点位 / 文本视图、演示面板分割线、1024 全屏关闭距右 16、夹爪标签列宽 88、程序列表长按菜单） | 建议 6、7 | 已排 |

建议顺序（和产品 P2-a/b/c 一致，最终由产品定）：先修必须 2（缺陷，开发小改）→ 工程列表、复制、模板向导 → 换产参数页（带改前改后）→ 历史和回滚、导出导入 → 下一轮 6 项穿插进去。

## 4. 要产品定的点
1. 料盘行 / 列 / 层改了以后：计数自动清零、问用户，还是禁止在没取完的时候改？示教点是要求重新示教，还是按间距自动算？
2. 已完成件数什么时候清零：首页加「开始新一批」，还是换盘、改件数时清零？目标件数改了要不要重新下发、核对？
3. 换产参数页里哪些项算 A 项，哪些改了不用重新示教、不用重新下发？
4. 复制工程以后：引用的程序、料盘是共用还是一起复制？复制出来的工程默认是待核对吗？
5. 版本回滚以后，引用它的工程怎么处理（跟最新并标黄，还是锁定版本）？
6. 工程名能不能重复（建议规则和程序一样：不能重名，去掉首尾空格比较）？
