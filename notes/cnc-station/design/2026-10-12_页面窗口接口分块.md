# 页面与窗口接口分块

> 2026-10-12。依据当前静态原型 `上下料/原型/cnc-prototype.html`（7 个菜单页 + 通用弹窗 / 抽屉 / 弹层）。
> 第一阶段：运动在 ARCS；门、卡盘、加工完成、允许取放走控制器 PLC；上位机不直连 CNC。设备 IO 只走采集子进程，页面状态只信 WebSocket。

## 拆法

| 种类 | 走哪 | 说明 |
|---|---|---|
| 工艺配置 | HTTP，按页整包保存 | 工程、程序、夹爪、料盘、信号组、设置。画布上的增删改在前端做完，点「保存」再提交 |
| 运行真值 | `WS /ws/robot` | 在线、步号、阶段、料盘格、件数、节拍、报警、信号实时值。禁止前端本地推算当真值 |
| 会动臂 / 写输出 / 下发 | HTTP 命令 | 单飞。运行中禁止覆盖正在执行的工程。软件停止不是急停 |
| 确认、菜单、未保存离开、适应画面、展开步骤 | 无接口 | 纯前端 |

引用检查（程序 / 料盘 / 夹爪「被 N 处引用」）用已加载的工程图在前端算。删除被拒时接口返回引用列表即可，不必单独做查询接口。

## 已有接口（对齐，不平行再做）

| 现有 | 处理 |
|---|---|
| `GET /api/system/health`、`GET /api/system/status` | 保留。首页「连接」弹层用 status + WS |
| `GET /api/robot/state` | 保留作断线补拉。页面常态不轮询，以 WS 为准 |
| `POST /api/robot/command` | 指令集与首页对不上。现有 `start/stop/reset/homing/servo_*`，`stop` 语义还是暂停。改成下面「运行」块，不要再叠一套 |
| `WS /ws/robot` | 保留。载荷按首页和信号页字段扩，见块 0 |
| `POST /api/process/script/generate` | 现模型是单工件点位，对不上工程图。改为「工程下发」里的生成步骤，旧入参废弃 |
| `GET /api/script/list`、`POST /api/script/send` | `send` 是裸 TCP 占位。生产下发改为上传 + `loadProgram` 核对，`sendall` 成功不算核对通过 |

## 块 0 · 横切（所有页都吃）

### WebSocket 快照（采集子进程推）

首页状态条、程序卡、四张数据卡、信号监视、料盘运行计数都订这一份。建议字段：

- 连接：机械臂在线、信号采集在线、心跳、各自最后更新时间
- 臂态：运行态 `idle / running / paused / alarm / done`、当前程序名、核对结果、速度倍率
- 步号：`STEP`、`PHASE`、当前模块、子阶段、步骤文案、本步已用时、循环序号
- 工件：夹持（空跑/有料）、碰撞等级、来源模块
- 产量：完成件数、目标件数、当前节拍、上一件节拍、本次报警次数、暂停次数、运行时长、开始时间
- 料盘：当前盘 id、层、格、整盘剩余、是否已取完、下一盘
- 结束：`done`、原因 `tray / target / signal`
- 信号：地址表上的 DI / DO / 寄存器当前值（信号页 150ms 级刷新靠这条，不另开轮询）

慢字段（关节、TCP）可降频附在同一通道，只给示教「记录当前位置」用。

|---|---|---|

| POST | `/api/auth/logout` | 弹窗「切换到操作员」 |

## 块 1 · 首页

页面：状态条、当前程序、模块进度、四张卡、信息提示、底栏开始 / 暂停 / 停止 / 速度。

| 方法 | 路径 | 页面对应 | 备注 |
|---|---|---|---|
| POST | `/api/run/start` | 开始 | 离线、未复位报警、引用失效、待核对、料盘未就绪 / 已取完、已达目标件数时拒绝，并回原因短句 |
| POST | `/api/run/pause` | 暂停 | |
| POST | `/api/run/resume` | 恢复 | |
| POST | `/api/run/stop` | 确认窗「停止当前运行？」 | 软件停止，不跑收尾。不是急停 |
| PUT | `/api/run/speed` | 速度 ±10%；运行中先弹「调整速度」 | 10% 一档，10–100。立即生效 |
| GET | `/api/events` | 信息列表、抽屉「全部信息」 | `level=alarm\|wait\|tip\|done`，报警未清除排前面 |
| GET | `/api/events/{id}` | 抽屉「报警详情 / 信息详情」 | |
| POST | `/api/events/{id}/recover` | 抽屉按钮「状态恢复」 | 工程师、操作员都可。恢复后不自动续跑 |
| GET | `/api/runtime/switches` | 弹层 + 抽屉「碰撞等级 / 夹持状态切换记录」 | 数据来自臂端上报，最近 N 条 |

无接口：

- 弹层「连接状态」：读块 0 的在线 / 心跳
- 弹层「当前料盘」：读块 0 的料盘字段
- 监控小窗 / 1024 浮窗 / 全屏：原型占位，本期不接视频流
- 「停止」「调速」确认框本身

## 块 2 · 工程编辑

页面：工程下拉、画布（手动顺序 / 料盘主循环）、右侧属性（模块属性 / 工程配置）、下发四步（生成 → 上传 → 加载 → 核对）。

属性栏在窄屏变成抽屉，数据与宽屏同一份，不另做接口。

| 方法 | 路径 | 页面对应 |
|---|---|---|
| GET | `/api/projects` | 顶栏工程下拉 |
| GET | `/api/projects/{id}` | 进入页：节点、`order`、`loop`、目标件数、空跑等级、功能开关、核对状态、受影响节点 |
| PUT | `/api/projects/{id}` | 「保存」。含画布上的调用、插入位、普通节点、碰撞等级、选中料盘 |
| POST | `/api/projects/{id}/deploy` | 「下发到机器人」。未保存则前端先保存。运行中拒绝 |
| GET | `/api/projects/{id}/deploy` | 顶栏四步 + 弹窗「下发状态」。进行中也可由 WS 推 `deploy` 进度 |

`PUT` 之后服务端把核对打回「待核对」。`deploy` 成功的定义是：文件进柜、`loadProgram`、读回程序名与 CRC，与 Int16Reg 4 一致。任一步失败，首页「开始」不可用。

这些弹窗不单独开接口，结果进同一次 `PUT`：

- 「将切换为料盘自动主循环」
- 「改为手动编排？」
- 「删除普通节点」
- 「先保存再下发」（前端顺序：`PUT` 然后 `deploy`）
- 子步骤碰撞等级覆盖

生成前校验放在 `deploy`：空跑等级 1–9 必填、取毛坯 / 成品下料已配置、引用的程序和料盘都在。失败原因回给按钮旁提示。

## 块 3 · 程序

页面：程序列表、步骤 / 点位 / 文本视图、夹爪控制、步骤属性。

| 方法 | 路径 | 页面对应 |
|---|---|---|
| GET | `/api/programs` | 左侧列表、工程里选程序 |
| POST | `/api/programs` | 弹窗「新建程序」 |
| GET | `/api/programs/{id}` | 步骤、夹爪、版本 |
| PUT | `/api/programs/{id}` | 「保存」。内容变了 `ver+1`，只改名不加版本。重名拒绝 |
| DELETE | `/api/programs/{id}` | 菜单「删除」。有引用则 409 + 引用列表（弹窗「不能删除」） |
| POST | `/api/programs/{id}/copy` | 菜单「复制」 |
| GET | `/api/points` | 「点位」Tab |
| PUT | `/api/points/{name}` | 保存点位坐标。改坐标会使引用它的程序待核对 |
| POST | `/api/teach/record` | 步骤属性 / 点位抽屉「记录当前位置」。读采集侧当前 TCP，写入该点 |
| POST | `/api/teach/move` | 「按住移动到此点」。按下开始、松开停止。只允许示教，不进自动生产 |

无接口：步骤菜单（复制 / 插入 / 上移 / 下移 / 删除）在前端改步骤数组，随 `PUT` 提交。文本视图由步骤生成；「切换为可编辑」若正式不做回写，则只读，无保存接口。弹窗「引用」用删除接口的引用列表，或前端算。

保存后若工程节点引用了变更程序，服务端标记受影响节点，核对状态回到待核对（与块 2 同一份 deploy 状态）。

## 块 4 · 夹爪

| 方法 | 路径 | 页面对应 |
|---|---|---|
| GET | `/api/grippers` | 整页：数量、每爪开/关/吹气/反馈 DI、超时、TCP、取料/放料模板 |
| PUT | `/api/grippers` | 「保存」。数量 1 / 2 / 4。减少数量前前端确认；被引用的爪删除后，工程侧重新选择 |
| POST | `/api/grippers/{id}/tcp` | 抽屉「标定 TCP」。四点记录用 `POST /api/teach/record` 的同一条臂端读位姿，本接口只提交 4 点并回算 TCP |
| POST | `/api/grippers/{id}/test` | 确认窗「手动测试」。写该爪打开 / 关闭 / 吹气。运行中拒绝 |

模板步骤弹窗「编辑模板步骤」随 `PUT /api/grippers` 提交。

## 块 5 · 料盘

三个配置 Tab + 运行计数。计数（`picked` / `placed`）不是料盘内容，不跟「保存」走，运行中由臂端寄存器回写，换盘 / 重置才由上位机清。

| 方法 | 路径 | 页面对应 |
|---|---|---|
| GET | `/api/trays` | 料盘下拉、工程选盘 |
| POST | `/api/trays` | 菜单「新建料盘」 |
| POST | `/api/trays/{id}/copy` | 「从其他料盘新建」 |
| PUT | `/api/trays/{id}` | 「保存」。规格、三点、层行列距、优先级、进入信号、夹爪模板、前后置、完成信号 |
| DELETE | `/api/trays/{id}` | 「删除当前料盘」。有引用则 409 |
| POST | `/api/tray-groups` | 弹窗「新建组合料盘」 |
| POST | `/api/trays/{id}/replaced` | 「已换盘」。取/放计数清零 |
| POST | `/api/trays/{id}/reset-count` | 确认窗「重置计数」。运行中拒绝 |
| PUT | `/api/trays/{id}/safe-point` | 弹窗「设置临时安全点位」 |
| POST | `/api/trays/{id}/test` | 确认窗「料盘整套抓取流程测试」。安全点 → 前置 → 取料 → 后置 → 回安全点。运行中禁用 |
| POST | `/api/teach/tray-move` | 料盘 / 料仓上的「移动到当前格、前置、后置」。示教，确认后执行 |
| GET | `/api/stations` | Tab「料仓」「料框·输送线」 |
| PUT | `/api/stations/{id}` | 同上保存 |
| GET | `/api/tray-common` | Tab「公共配置」 |
| PUT | `/api/tray-common` | 同上 |

无接口：规格变化提示「料盘规格已变」、复制后「对应数据是否已修改」、空白项「存在空白配置项」、行详情抽屉。都是保存前的前端确认。料仓行详情只是把当前行摊开。

前后置动作抽屉里的点位和信号组，分别落到点位接口和信号组接口，抽屉本身不新开资源。

## 块 6 · 信号

实时值只来自 WS。本页在「机械臂端」控制方式下默认只读。

| 方法 | 路径 | 页面对应 |
|---|---|---|
| GET | `/api/signals` | 监视、信号列表。名称、类型、地址、谁写、分组。值不在这里取 |
| PUT | `/api/signals/{key}` | 抽屉里改名称、分组（工程师） |
| GET | `/api/signals/{key}/history` | 抽屉「最近 10 次变化」 |
| POST | `/api/signals/{key}/write` | 确认窗「测试写入」。仅 DO，调试。运行中、非工程师拒绝。不参与联锁 |
| GET | `/api/signal-groups` | Tab「信号组」 |
| PUT | `/api/signal-groups` | 「保存」。新建、添加信号、改组内作用、删除未引用组 |
| PUT | `/api/end-signal` | 监视页「结束信号」。改完即存。只允许 DI 或空 |
| POST | `/api/signals/import/preview` | Tab「导入」选文件后的前 20 行，标出地址冲突 |
| POST | `/api/signals/import` | 确认窗「导入」。冲突行跳过还是覆盖，请求里写明 |

无接口：筛选弹窗「更多筛选」、删除被引用组时的「不能删除」（`PUT` 时 409）。顶栏「信号控制端」跳到设置，不在本页写。

## 块 7 · 设置

| 方法 | 路径 | 子页 | 备注 |
|---|---|---|---|
| GET | `/api/settings` | 整页 | |
| PUT | `/api/settings/features` | 可选功能 | 翻转台、二次定位、点位组。关掉某功能时，工程里对应开关一并关 |

密码走块 0。点位组、配置/变量组合原型只有入口，第一阶段不做读写接口。

## 不做

- 逐步点动指挥自动轨迹
- 上位机写门、卡盘、加工完成、允许取放（第一阶段这些是 PLC → 程序）
- `IP:30001` 裸 TCP 当生产下发
- 恢复示例数据、原型演示面板
- 监控视频流

## 建议落地顺序

1. 块 0：WS 快照 + 会话。首页能显示真值，还不能可靠开工。
2. 块 1 运行命令 + 块 2 工程保存 / 下发核对。替换现有 `command` 与 `script/send`。
3. 块 3、4、5 的保存。示教 `record` / `move` / 料盘测试放在保存之后。
4. 块 6 信号目录、结束信号、测试写入；块 7 设置。
5. 信号导入、组合料盘、点位组、变量组合。
