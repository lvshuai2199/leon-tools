# C++ 后端目录结构

> 2026-10-12。对齐《页面窗口接口分块》和「主进程不碰设备、采集子进程独占 IO」。
>
> 假设：用 C++ 替换现有 `backend/`（Python FastAPI），不在 Python 旁边再挂一层。HTTP 用 cpp-httplib，WebSocket 用 ixwebsocket，JSON 用 nlohmann/json，工艺库用 SQLite。控制器走遨博 C++ SDK（`RuntimeMachine` / `RegisterControl` / `RobotState`），不再用 `pyaubo-sdk`。换 HTTP 库只动 `src/api` 和 `src/ws`，目录不动。

## 进程

```
Vue ── HTTP / WS ──► stationd          不链接 aubo SDK，不读控制器
                      │ 本机 IPC（状态上行，命令下行）
                      ▼
                    collectord         唯一持有 SDK 长连接
                      │
                      ▼
                    ARCS / PLC
```

`stationd` 启动并看守 `collectord`。请求线程只读写 SQLite 和 IPC，不等控制器。

## 谁链接谁

| 目标 | 链什么 | 不链什么 |
|---|---|---|
| `stationd` | `api` `ws` `runtime` `domain` `ipc` `store` `snapshot` | aubo SDK、`adapter/` |
| `collectord` | `ipc` `snapshot` `adapter/`、aubo SDK | HTTP、SQLite 业务表 |
| `tests` | `domain`，必要时 `ipc` 协议 | SDK、端口 |

`address_table.json` 由两边读。改地址只改这一份，Lua 模板和 PLC 对照同一张表。

## 目录和页面的对应

| 页面 | HTTP | 规则 | 落到控制器 |
|---|---|---|---|
| 横切 / 首页真值 | `ws/hub.cpp` | `snapshot/` | `collectord` 快通道：Reg 0–6、联锁、运行态 |
| 首页命令 | `run_api.cpp` `event_api.cpp` | `runtime/run_service.cpp` | IPC：start / pause / resume / stop / speed / recover |
| 工程编辑 | `project_api.cpp` | `domain/project.cpp` `refs.cpp` | `deploy_service.cpp` 编排；上传和 `loadProgram` 在 `aubo_c5.cpp` |
| 程序 / 点位 | `program_api.cpp` | `program.cpp` `point.cpp` | 示教 `teach/record`、`teach/move` 经 IPC，只在非自动生产时执行 |
| 夹爪 | `gripper_api.cpp` | `gripper.cpp` | TCP 标定读当前位姿；手动测试写 DO |
| 料盘 | `tray_api.cpp` | `tray.cpp` `station.cpp` | 换盘/清计数写配方寄存器；整套测试、移到格位走示教命令 |
| 信号 | `signal_api.cpp` | `signal_catalog.cpp` `signal_group.cpp` | 实时值只从快照来；测试写入仅 DO |
| 设置 | `settings_api.cpp` `auth_api.cpp` | `settings.cpp` | 主站参数只落库，本期不连接 |

`domain/` 在保存时做引用和版本。采集进程不解释工程图。
