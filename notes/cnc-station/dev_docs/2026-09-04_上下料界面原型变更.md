## 一、本次改动背景

根据设计图（图 1 料盘配置区草图 + 图 2 信号表布局），对料盘页面进行逻辑改造，并按后续沟通澄清调整了公共配置的组织方式。

## 二、改动内容

### 1. 料盘面板改造（按图 2）

- 信号表由 2 张（料盘进入信号 / 取料完成信号）扩展为 4 张：
  **料盘读入信号、前盘点、后盘点、取料完成**
- 前盘点 / 后盘点的位置下拉仅限**当前料盘**的点位（P1–P7、?），不可跨料盘选择
- 新增保存按钮与黄色逻辑规则提示卡

### 2. 料盘配置弹窗重做（按图 1）

- 顶部：料盘名称 + 保存 + 记录料盘原点
- 中部：2×4 圆点点位网格（点击选中）+ 操作按钮（移动侧位 / 点位空走 / 测试 / 对齐 / 修正）+ 物料获取方式 / 抓取方式
- 底部：网格规格（行 / 列 / 间距 / 物料高度 / 抬升间距等）+ 设备动作（测量前端动作设置 / 设备前端安全点位 / 料盘装载抓取流程测试）

### 3. 公共配置区：料盘 / 料仓共用

- **定位澄清**：料盘读入信号、前盘点、后盘点、取料完成信号为料盘与料仓的**公共配置**，可修改，但大多数情况无需变动
- 组织方式：升级为与「料盘」「料仓」**同级的第三个 Tab**（料盘 / 料仓 / 公共配置）
- 料盘 Tab 只保留料盘列表，料仓 Tab 保持原样

### 4. 料盘料仓全局动作测试

- **使用场景**：仅在料盘 / 料仓**整体功能测试**时使用
- **前提**：必须先设置一个**外部安全点**（未设置时点击测试会被拦截）
- **执行逻辑**：不走机床内动作，按以下顺序执行

```
安全点 → 前置动作 → 料盘动作 → 后置动作 → 安全点
```

- 界面提供：外部安全点下拉选择、记录 / 清除安全点、测试按钮、五步执行步骤条（执行中高亮、完成变绿）

## 三、已确认的逻辑规则

| 规则 | 说明 |
|---|---|
| 前后盘信号组独立配置 | 不强制一一对应 |
| 前 / 后盘点仅当前料盘 | 不可跨料盘选点 |
| 组合多盘锁定 | 组合多盘模式下保存后不联动修改其他料盘 |
| 公共配置共用 | 料盘 / 料仓两侧共用同一份信号与点位配置 |
