## 1. 图标题行（`.graph-head`）

仍是图面板顶上的一行，不换行，不另起一列。高度保持 40px（现在 41px）。padding 改为 `4px 12px`，`align-items: center`（现在是 baseline，32px 控件会对不齐）。`flex-wrap: nowrap`。gap 保持 10px。

从左到右，都在这一行里：

1. `b`「分支图」。14px，`flex: none`。沿用 `.graph-head b`。
2. `span`「正在看：全部」或「正在看：」加分支名。12px，`#656d76`，沿用 `.graph-head span`。`flex: none`，`max-width: 240px`，超出省略，`title` 放全文。这一句替换现在那句「和左侧分支在同一页…」，不要两句并列。
3. `button`「全部」。高 32px，padding `0 12px`，字号 14px，`flex: none`。正在看全部时加 `is-on`，颜色用 `.tabs button.is-on`（底 `#ddf4ff`，字和边 `#0969da`）。正在看某一条时用普通白按钮，作为回到全部的入口。
4. `select`。宽 220px，高 32px，字号 14px，`flex: none`。必须压过全局 `select { width: 100% }`，不要拉满整行。不要用 `.history-bar select` 的 120px。第一项文字是「全部」，其余是分支名。收起时显示的文字与旁边的「正在看」一致。

无提交时，这一行仍留在 `.graph-pane` 顶部，不要只剩「还没有提交」把「全部」和「正在看」盖掉。

这一行内宽约 1136px。上面四项最长大约：42 + 10 + 240 + 10 + 54 + 10 + 220 ≈ 586px，放得下。`span` 先省略，select 不缩小。

## 2. 左侧按钮（`.branch-actions`）

不要再插在 `#branch-filter` 和 `.list.grow` 之间。左栏顺序改为：

1. `#branch-filter`（保持 38px）
2. `.list.grow`（`flex: 1`，紧贴过滤框，选中分支时第一行不下移）
3. `.branch-actions`（贴在树下面、`.stash-block` 上面）
4. `.stash-block`（位置不动）

按钮区从树的底部占高度，不从顶部把树顶下去。

左列从 240px 改为 **268px**（`.screen.history` 第一列）。padding 仍是 12px，内宽 244px。1440 下文件列大约少 13px、diff 大约少 15px，四格关系不变。244px 才能让四个 14px 按钮排成一行；维持 214px 时「接到后面」会再掉到第二行。

`.branch-actions` 现在和 `.toolbar` 共用 `flex-wrap: wrap; gap: 8px`，这是换行的原因。左栏里这条要单独压过：

- `flex: none`
- `flex-direction: column`
- `flex-wrap: nowrap`
- `gap: 4px`
- `max-height: 56px`
- `margin: 6px 0 0`
- `overflow: hidden`

按钮放在内部一行 `.branch-actions__row`：`display: flex; flex-wrap: nowrap; align-items: center; gap: 4px; height: 32px`。按钮高 32px（现有 `button` 的 `min-height`），字号 14px，padding `0 6px`（全局是 `0 12px`，四个词在 244px 里要用 6px）。不要均分宽度，不要省略按钮文字。

按 14px 字宽加 padding 6px 和 1px 边框：切过去约 56、合进来约 56、接到后面约 70、删除约 42，gap 4×3 = 12，合计约 236px。244px 内宽剩约 8px。远程没有删除，三个按钮更松，仍是这一行。

当前分支同一块，最多两行，总高 56px：

- 第一行 `.meta`：13px，`#656d76`，高 20px，`margin: 0`（压过 `.meta` 的 `margin: 0 0 8px`），一行省略。「你在「feat/local-git-history」。」13px 约 177px，244px 里放得下。更长的名字省略，`title` 放全文。
- 第二行只有「合成最近几次」。这一个按钮用默认 padding `0 12px`，宽约 110px，左对齐，不拉满。

不要第三行。贮藏里的「还原 / 丢弃」仍留在 `.stash-block` 里，不挪到树下面；同样一行 32px，不换行。

## 3. 勾选提交的对话框（`.modal`）

沿用 `.modal` 遮罩（`padding: 16px`，居中）和 `.modal__card` 的白底、圆角 10px、padding 16px。不要改设置、确认那种短对话框。这种列表对话框加修饰类 `.modal__card.is-commits`，避免被现在的 `width: min(520px, 100%)` 和 `p { max-height: 50vh }` 带着走。520px 内宽约 488px，一行里放不下「说明 + 短 hash + 作者 + 时间」。

`.modal__card.is-commits`：

- 宽 `min(680px, calc(100vw - 32px))`
- `max-height: calc(100vh - 48px)`（900 高时卡片最多 852，上下留空）
- `display: flex; flex-direction: column; overflow: hidden`
- 只有列表滚动，卡片本身不滚动，不高于视口

从上到下，间距用现有 8 / 12：

1. `h2`。16px，`margin: 0 0 8px`，沿用 `.modal__card h2`。`flex: none`。
2. 一行说明。14px，`#656d76`，高 20px，`margin: 0 0 8px`，一行省略，`title` 放全文。`flex: none`。不要用现在 `.modal__card p` 的 `max-height: 50vh` 把说明做成半屏滚动区。
3. 列表。`flex: 1; min-height: 72px; overflow-y: auto`。边框 `1px solid #d8dee4`，圆角 6px。这是唯一滚动的区域。30 行时只滚这里。
4. 说明输入框。`flex: none`，`margin-top: 10px`，高 56px，`resize: none`，字号 14px。压过全局 `textarea { min-height: 72px }`，避免输入框把列表挤出视口。
5. `.modal__actions`。`flex: none`，`margin-top: 12px`，沿用右对齐、`gap: 8px`。两个按钮，高 32px。右侧那个用现有 `.primary`。禁用仍是 `opacity: 0.55`。

列表每一行高 36px，和 `.item` 的 `min-height: 36px` 相同，不要用 `.graph-line` 的 56px（那是说明加辅助两行）。`display: flex; align-items: center; gap: 8px; padding: 0 8px`。一行，不换行。

- 勾选框：`flex: none`
- 说明：14px，`#1f2328`，`flex: 1; min-width: 0`，省略
