# 本机 Git 工具

日期：2026-10-14  
项目：local-git（本机 Windows 工具，不进 LeonPro）

双击 `启动.bat`，浏览器里打开这台电脑上已有的仓库。克隆、推拉只用 GitHub / Gitee 的 https。令牌写在本机 `config.json`，不进仓库。

## 已做

- 分支树：HEAD、本地、远程（按 remote 分组，`feature/foo` 再按 `/` 分层）。从树上检出。合并、变基、删除只出现在选中的分支上。可以过滤分支。
- 脏工作区切分支：确认后 `stash push -u`，切过去再还原。还原冲突就取消还原，贮藏留下，工作区保持干净。拉取、合并、变基、拣选仍要求工作区干净。冲突直接取消。
- 变更：未暂存 / 已暂存两段，按一级目录分组。勾选才 `git add`，提交只提交 index。左列占满剩余高度，列表滚动，提交说明贴在底部。「变更」tab 显示未提交文件数。文件名加上级目录，`title` 为全路径。
- 对比：点未提交文件，右侧左右对比。未暂存是工作区对暂存区，已暂存是暂存区对 HEAD。未暂存且非冲突的文件可以按 hunk 回滚。未跟踪文件回滚是删除。
- 日志：`--all` 提交图，本地 / 远程标签颜色分开。说明一行，短 hash、作者、时间第二行。点提交先看文件，再看 unified diff，可整次或按 hunk 拣选。
- 贮藏：列表、还原、丢弃、查看 diff。工作区不干净时不能还原。

## 还没做

- 变更列表按关键字过滤。
- 左右列拖宽。
- 一次回滚多个文件。现在勾选只负责暂存，回滚只作用于当前点开的那一个文件。

## 不做

Shelve、changelist、三方合并、交互式 rebase、拖拽暂存 hunk、提交签名、GitHub PR、深色皮肤、SourceTree 图标主题、强制丢弃后切分支。不改 personal-server。不加 npm 依赖。
