# 焊缝创建流程与点位类说明

## 1. 说明范围

本文说明 WeldingTools 项目中以下两类焊缝的创建和执行流程：

1. 单直线焊缝。
2. 多层多道焊缝。

重点说明：

- 两种焊缝在任务树上的结构差异。
- 起弧点、直线点、结束点分别由哪些类创建。
- 点位示教数据保存在哪些字段中。
- `MultiPathManager` 在多层多道流程中的作用。

本文中的“起弧点”指焊接段开始处的 `WeldStartTaskNodeContribution`，不是普通的进枪点。

## 2. 相关核心类

| 作用 | 类 |
| --- | --- |
| 焊接工具总入口 | `WeldToolTaskNodeContribution` |
| 普通单段焊接根节点 | `WeldTaskNodeContribution` |
| 多层多道根节点 | `WeldMultiPassTaskNodeContribution` |
| 单道焊接段 | `WeldRunTaskNodeContribution` |
| 起弧点 | `WeldStartTaskNodeContribution` |
| 普通点位，包括进枪点和结束点 | `WeldPointTaskNodeContribution` |
| 直线焊接段 | `WeldLinearTaskNodeContribution` |
| 直线/圆弧点位数据基类 | `WeldLinearTaskNodeAbstract` |
| 普通点位数据基类 | `WeldPointTaskNodeAbstract` |
| 多路径几何中间模型 | `MultiPathManager`、`MultiPathNode` |

## 3. 单直线焊缝创建流程

### 3.1 创建入口

创建单直线焊缝的入口是：

```java
WeldToolTaskNodeContribution.addWeldNode(true)
```

对应代码：

`src/main/java/cn/elibot/plugin/processes/weldingtools/impl/task/weldtool/WeldToolTaskNodeContribution.java`

该方法会创建：

```text
WeldToolTaskNodeContribution
└── WeldTaskNodeContribution
    ├── WeldPointTaskNodeContribution       // 进枪点
    ├── WeldStartTaskNodeContribution       // 起弧点
    │   └── WeldLinearTaskNodeContribution  // 直线焊接点
    └── WeldPointTaskNodeContribution       // 结束点
```

核心代码位置：

- `addWeldNode(true)`：约第 359 行。
- 创建进枪点：约第 364-369 行。
- 创建起弧点：约第 370-372 行。
- 创建直线点：约第 373 行。
- 创建结束点：约第 374-379 行。
- 将直线点加入起弧点的子节点：约第 388-390 行。

### 3.2 用户设置点位

普通点位的“设置点位”流程位于：

```text
WeldPointTaskNodeAbstract.setPoint()
    -> RobotMovementService.requestUserToSetPosition()
    -> 保存当前 TCP Pose 和 JointPositions
```

数据保存到：

```java
movePoseKey
moveJointKey
```

因此，以下节点共用这套数据结构：

- 进枪点：`WeldPointTaskNodeContribution`
- 起弧点：`WeldStartTaskNodeContribution`
- 结束点：`WeldPointTaskNodeContribution`

相关代码：

- `src/main/java/cn/elibot/plugin/processes/weldingtools/impl/task/base/point/WeldPointTaskNodeAbstract.java`
- `setPoint()`：约第 87-97 行。
- `getMovePose()`：约第 162-164 行。
- `setPointPose()`：约第 178-180 行。

### 3.3 直线点设置

直线点由具体类：

```java
WeldLinearTaskNodeContribution
```

承载，它继承自：

```text
WeldLinearTaskNodeContribution
└── WeldShapeTaskNodeContribution
    └── WeldLinearTaskNodeAbstract
```

直线点的 Pose 和关节数据字段是：

```java
linearMovePoseKey
linearMoveJointKey
```

设置点位时调用：

```java
setLinearPoint()
    -> setPoint(linearMovePoseKey, linearMoveJointKey)
```

相关代码：

`src/main/java/cn/elibot/plugin/processes/weldingtools/impl/task/base/linear/WeldLinearTaskNodeAbstract.java`

- `linearMovePoseKey`：约第 30 行。
- `setLinearPoint()`：约第 64-66 行。
- `getLinearMovePose()`：约第 123-125 行。

### 3.4 脚本生成顺序

`WeldTaskNodeContribution.generateScript()` 会按照任务树顺序执行子节点。

执行顺序可以理解为：

```text
1. 执行进枪点
2. 执行 WeldStartTaskNodeContribution
   2.1 移动到起弧点
   2.2 创建焊接轨迹命令
   2.3 执行 WeldLinearTaskNodeContribution
   2.4 关闭电弧
3. 执行结束点
```

相关代码：

- `WeldTaskNodeContribution.generateScript()`：`task/weld/WeldTaskNodeContribution.java` 约第 327-332 行。
- `WeldStartTaskNodeContribution.generateScript()`：`task/weldstart/WeldStartTaskNodeContribution.java` 约第 150-169 行。
- 直线段命令生成：`WeldTaskNodeContribution.java` 中的 `getBaseCommandList()`。

直线焊接段最终生成的是：

```java
new MoveLCommand(...)
```

## 4. 多层多道焊缝创建流程

### 4.1 创建初始多道结构

入口是：

```java
WeldToolTaskNodeContribution.addMultiPassNode()
```

初始结构为：

```text
WeldToolTaskNodeContribution
└── WeldMultiPassTaskNodeContribution
    └── WeldRunTaskNodeContribution       // 第一道
        ├── WeldPointTaskNodeContribution // 进枪点
        ├── WeldStartTaskNodeContribution // 起弧点
        │   └── WeldLinearTaskNodeContribution
        └── WeldPointTaskNodeContribution // 结束点
```

核心代码：

`src/main/java/cn/elibot/plugin/processes/weldingtools/impl/task/weldtool/WeldToolTaskNodeContribution.java`

- 创建 `WeldMultiPassTaskNodeContribution`：约第 449-452 行。
- 创建 `WeldRunTaskNodeContribution`：约第 453 行。
- 创建进枪点：约第 454-459 行。
- 创建起弧点：约第 460-462 行。
- 创建直线点：约第 463 行。
- 创建结束点：约第 464-469 行。
- 组装任务树：约第 478-483 行。

### 4.2 新增第二道、第三道

多层多道面板确认新增焊道后，会调用：

```java
WeldMultiPassTaskNodeContribution.newMultiPass(...)
```

新增焊道的大致流程是：

```text
1. 选择一条已有焊道作为基础焊道。
2. 读取基础焊道下的所有点位。
3. 通过 OffsetTaskNodeDomain 复制任务树。
4. 创建 MultiPathManager。
5. 根据 up/out 参数计算路径偏移。
6. 把偏移后的 Pose 写回新焊道。
7. 设置新焊道的工作角、前进角和左右视图。
```

对应代码：

- 面板确认新增焊道：`task/basepanel/multipasspanel/BaseWeldMultiPassPanel.java` 约第 538-552 行。
- 新增和偏移流程：`task/weldmultipass/WeldMultiPassTaskNodeContribution.java` 约第 456-501 行。
- 将新 Pose 写回任务节点：约第 534-559 行。

### 4.3 多层多道的最终结构

完成多道创建后，结构类似：

```text
WeldMultiPassTaskNodeContribution
├── WeldRunTaskNodeContribution // 第一道
│   ├── WeldPointTaskNodeContribution
│   ├── WeldStartTaskNodeContribution
│   │   └── WeldLinearTaskNodeContribution
│   └── WeldPointTaskNodeContribution
├── WeldRunTaskNodeContribution // 第二道
│   ├── WeldPointTaskNodeContribution
│   ├── WeldStartTaskNodeContribution
│   │   └── WeldLinearTaskNodeContribution
│   └── WeldPointTaskNodeContribution
└── WeldRunTaskNodeContribution // 第三道
```

所以，多层多道并没有重新设计一套新的起弧点和直线点类。每一道仍然复用：

- `WeldPointTaskNodeContribution`
- `WeldStartTaskNodeContribution`
- `WeldLinearTaskNodeContribution`

区别是这些点位被放在不同的 `WeldRunTaskNodeContribution` 下，并且后续焊道的 Pose 通常由第一道偏移得到。

## 5. 三类关键点位的类对应关系

| 业务含义 | 具体任务节点类 | 数据基类 | Pose 字段 |
| --- | --- | --- | --- |
| 进枪点 | `WeldPointTaskNodeContribution` | `WeldPointTaskNodeAbstract` | `movePoseKey` |
| 起弧点 | `WeldStartTaskNodeContribution` | `WeldPointTaskNodeAbstract` | `movePoseKey` |
| 直线点 | `WeldLinearTaskNodeContribution` | `WeldLinearTaskNodeAbstract` | `linearMovePoseKey` |
| 结束点/退枪点 | `WeldPointTaskNodeContribution` | `WeldPointTaskNodeAbstract` | `movePoseKey` |

需要特别注意：

`WeldStartTaskNodeContribution` 虽然表示起弧点，但它本身继承的是普通点位基类：

```java
WeldStartTaskNodeContribution
    extends WeldPointTaskNodeAbstract
```

因此它的起弧 Pose 仍然保存在 `movePoseKey` 中。

## 6. MultiPathManager 的作用

`MultiPathManager` 不是任务节点创建类，而是多道偏移使用的几何中间模型。

它通过以下方法收集路径：

```java
addStartPoint(Pose)
addLinePoint(Pose)
addCirclePoint(Pose, Pose)
```

对应数据模型是：

```text
MultiPathNode
├── START_NODE -> startNodePnt
├── LINE_NODE  -> lineEndPnt
└── ARC_NODE   -> arcPassPnt、arcEndPnt
```

相关文件：

- `src/main/java/cn/elibot/plugin/processes/weldingtools/impl/domain/MultiPathManager.java`
- `src/main/java/cn/elibot/plugin/processes/weldingtools/impl/domain/MultiPathNode.java`

在 `createMultiPathManager()` 中：

- `WeldPointTaskNodeAbstract` 会调用 `addStartPoint()`。
- 线性 `WeldShapeTaskNodeContribution` 会调用 `addLinePoint()`。
- 圆弧 `WeldShapeTaskNodeContribution` 会调用 `addCirclePoint()`。

因此，`MultiPathNode.START_NODE` 的含义更接近“普通路径点”，不一定只代表真正的起弧点。

## 7. 最终结论

### 单直线焊缝

```text
WeldToolTaskNodeContribution
    -> WeldTaskNodeContribution
        -> WeldPointTaskNodeContribution
        -> WeldStartTaskNodeContribution
            -> WeldLinearTaskNodeContribution
        -> WeldPointTaskNodeContribution
```

### 多层多道焊缝

```text
WeldToolTaskNodeContribution
    -> WeldMultiPassTaskNodeContribution
        -> WeldRunTaskNodeContribution
            -> WeldPointTaskNodeContribution
            -> WeldStartTaskNodeContribution
                -> WeldLinearTaskNodeContribution
            -> WeldPointTaskNodeContribution
        -> WeldRunTaskNodeContribution
        -> ...
```

### 点位类结论

- 起弧点：`WeldStartTaskNodeContribution`
- 直线点：`WeldLinearTaskNodeContribution`
- 结束点：`WeldPointTaskNodeContribution`
- 多层多道的偏移中间模型：`MultiPathManager`
- 多层多道的几何节点模型：`MultiPathNode`
