# EDGE工作台修改与操作记录

## 2026-09-04

### 本次修改

- 扩展名称由“起始页工作台”统一调整为“EDGE工作台”，加载目录保持 `edge-start-hub` 不变。
- 扩展版本更新为 `1.1.0`。
- 主页面移除顶部品牌栏和设置按钮，快捷检索弹窗也不再提供设置入口；设置统一从 Edge 扩展图标的右键菜单进入。
- 收藏夹继续按 Edge 原有文件夹分组，每个分组默认全部展开。
- 收藏夹改为四列紧凑卡片，显示图标、标题、所属文件夹和数量，卡片使用轻微区分的浅色背景。
- 右键书签卡片新增菜单：
  - 在新标签页中打开
  - 在新窗口中打开
  - 在隐身窗口中打开
  - 展示二维码
  - 置顶 / 取消置顶
  - 编辑
  - 复制网址
  - 隐藏 / 取消隐藏
  - 删除
- 置顶、隐藏状态保存在扩展本地存储；设置页新增“显示已隐藏的收藏”，用于找回隐藏书签。
- 收藏卡片支持拖动排序；同一分组拖动会调整 Edge 收藏夹顺序，拖到其他已展开分组会同步移动到对应收藏夹文件夹。
- 主页面点击常用网页、自定义网站、收藏夹和搜索结果时统一在新标签页打开，当前工作台标签页保持不变。
- 编辑和删除直接调用 Edge 收藏夹 API；删除会先要求确认。
- 二维码按需使用 QuickChart 生成，仅在用户点击“展示二维码”时发送当前网址。
- 地址映射兼容完整 URL、裸 IP/域名、`/*` 后缀，以及换行、逗号、分号分隔；设置页显示当前规则命中的收藏链接数量。

### 操作记录

1. 修改 `manifest.json`：增加 QuickChart 主机权限和隐身窗口所需的窗口权限。
2. 修改 `shared/storage.js`：增加 `pinnedBookmarkIds`、`hiddenBookmarkIds`、`showHiddenBookmarks` 默认字段。
3. 修改 `shared/url-rules.js`：增强前缀规范化、默认端口和裸主机匹配。
4. 修改 `pages/newtab/index.html`、`newtab.js`、`newtab.css`：加入右键菜单、编辑/二维码弹窗、置顶隐藏删除动作和分组卡片布局。
5. 修改 `pages/settings/index.html`、`settings.js`：增加隐藏书签显示设置和旧规则兼容读取。
6. 修改 `assets/icons.svg`：增加打开标签、窗口、隐身、二维码、置顶、编辑、链接、隐藏等图标。
7. 为收藏卡片增加 HTML5 拖放处理，通过 `chrome.bookmarks.move` 将排序和跨分组移动同步回 Edge 收藏夹。
8. 为主体链接设置新标签页打开行为；搜索提交通过 `chrome.tabs.create` 创建新标签。

### 验证操作

在 `edge-start-hub` 目录执行：

```powershell
npm test
```

结果：5 项地址映射测试全部通过；所有 JavaScript 文件语法检查通过；manifest 中引用的页面、脚本和图标文件均存在。

### 使用操作

1. 打开 `edge://extensions/`，在“EDGE工作台”卡片上点击“刷新”。
2. 打开新标签页，在任意收藏夹卡片上点击鼠标右键即可看到新菜单。
3. 设置不再显示在主页面；在 Edge 扩展工具栏图标的右键菜单中选择“扩展选项”进入设置。
