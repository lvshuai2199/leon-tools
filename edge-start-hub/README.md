# EDGE工作台（Edge 扩展）

一个无需构建、可直接加载到 Microsoft Edge 的 Manifest V3 扩展。

## 安装

1. 在 Edge 地址栏打开 `edge://extensions/`。
2. 打开左侧的“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择本目录 `edge-start-hub`。
4. 新建标签页，或按 `Ctrl+Shift+K` 打开快速检索。

如快捷键发生冲突，在 `edge://extensions/shortcuts` 中重新分配。

## 功能

- 新标签页以“推荐”卡片网格展示常用网页、自定义网站，并按原收藏夹文件夹分组、默认全部展开显示。
- 收藏卡片可拖动调整顺序，也可拖到另一个已展开分组；变更会同步到 Edge 收藏夹。
- 快捷搜索优先匹配当前已打开的本地标签页，其次为收藏夹、自定义网站和历史记录。
- 可选在 Edge 启动时自动打开工作台。
- 地址映射规则可绑定收藏夹文件夹。点击工作台中的收藏夹卡片时自动替换 URL 前缀，也可手动批量写回收藏夹 URL；旧前缀支持每行、逗号或分号分隔，也可直接填写裸 IP/域名（自动按 `http://` 处理）。
- 所有设置仅保存在当前 Edge 配置文件的扩展本地存储中。

## 地址映射示例

旧前缀填入 `http://192.168.1.20:8080`，当前前缀填入 `http://192.168.1.35:8080`。绑定某个收藏夹文件夹后，该文件夹中的链接会保留原路径，只替换服务器地址和端口。
