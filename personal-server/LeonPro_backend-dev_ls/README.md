# Git代码提交规范

```
feat: 新功能（feature）

fix: 修补bug

docs: 只改变了文档

style: 改变了空格、格式化、缺少分号等，不影响代码运行

refactor: 重构（即不是新增功能，也不是修改bug的代码变动）

test: 增加测试

chore: 构建过程或辅助工具的变动
```
