# LeonTools

个人工具 monorepo（脚本、小工具、开发辅助）。

## 相关仓库

| 仓库 | 说明 |
|------|------|
| [lvshuai2199/leon-notes](https://github.com/lvshuai2199/leon-notes) | 个人笔记（含 cnc-station / weldingtools 等文档） |
| [lvshuai2199/personal-server](https://github.com/lvshuai2199/personal-server) | LeonPro 个人服务器（前后端与部署），已从本仓拆出 |

## 本仓库主要目录

- `can_tester_linux` — CAN 测试
- `cursor-usage-widget` — Cursor 用量小组件
- `edge-start-hub` — Edge 启动聚合
- `git-picbed` — Git 图床相关
- `history` — 历史资料
- `leonpro-dev-hub` — LeonPro 开发辅助
- `local-git` — 本地 Git 工具
- `pics` — 图片
- `stm32-servo` — STM32 舵机相关

根目录另有简要故障排查笔记等。
