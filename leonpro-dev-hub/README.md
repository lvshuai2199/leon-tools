# LeonPro 本地启动台

Windows 本机控制台，用来选数据库、选前端接口目标，然后分别或一键启停 Vue / 手机 H5 / Spring Boot。

技术：Node 标准库 HTTP + 本地网页。不装依赖，双击 `启动.bat` 即可。

## 用法

1. 安装 Node.js。
2. 双击 `启动.bat`，浏览器打开 `http://127.0.0.1:3780`。
3. 选 Dev/Prod 库（只影响本机 Spring Boot）。
4. 选前端连本地 8089 还是远端服务器。
5. 启动单个服务，或一键全开 / 全关。
6. SSH 卡片可测试连接、开关隧道。部署按钮会跑各项目 `deploy/deploy.ps1`。

本机 Spring Boot 不会直连公网 3306。启动后端时会用 `deploy.env` / `bootstrap.env` 里的 SSH 账号，把服务器 `127.0.0.1:3306` / `6379` 转到本机 `13306` / `16379`。

前端接口切换后，需要重新启动 Vue / 手机 H5 才会生效。重启启动台后新逻辑才生效。
