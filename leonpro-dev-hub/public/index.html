LeonPro 本地启动台

本机启停 Spring / Vue / 手机 H5

Spring Boot 数据库

只影响本机后端。会先走 SSH 隧道连服务器 MySQL（公网 3306 不通）。Prod 用 leonpro_db_prod。

前端接口目标

本地走本机 8089。服务器端经 SSH 转到本机 18089（公网 8089 不通）。

SSH 连接

账号来自 bootstrap.env / 各项目 deploy.env，不会在页面显示密码。

部署到服务器

调用对应目录的 deploy/deploy.ps1。Spring 走 Docker，Vue 到网站根目录，手机 H5 到 /h5/。

服务器

SSH 隧道、部署、远端 API 都用这个主机。密码仍只从 deploy.env / bootstrap.env 读取。

项目目录

相对启动台目录或绝对路径。保存后立刻用于启停和部署，无需重启启动台。
