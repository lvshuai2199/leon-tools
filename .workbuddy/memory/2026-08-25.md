## pnpm 安装踩坑（Windows + WorkBuddy 环境）
- `NODE_OPTIONS` 被注入 `genie-safe-delete.cjs` shim，会拦截 pnpm 删临时文件 → 必须 `env -u NODE_OPTIONS pnpm ...`
- 默认 store `D:\.pnpm-store\v11` 的 SQLite 报 "attempt to write a readonly database" → 换 `--store-dir C:/Users/admini/.pnpm-store-leon` 解决；注意项目 `.npmrc` 的 store-dir 在 pnpm 11 下未生效，必须命令行传参
- Windows 无符号链接权限 → `--config.node-linker=hoisted`（扁平 node_modules）
- npmjs/npmmirror 网络极慢，供应链检查要 8 分钟 → 后台运行 + `--fetch-timeout=300000 --fetch-retries=5`
- CI 环境 frozen-lockfile 报错时用 `--no-frozen-lockfile`
- 成功安装命令模板：`env -u NODE_OPTIONS CI=true pnpm install --no-frozen-lockfile --store-dir "C:/Users/admini/.pnpm-store-leon" --config.node-linker=hoisted --fetch-timeout=300000 --fetch-retries=5`

## RFrame 坐标系类讲解 + 文档
- RFrame = 参考坐标系，等价 4x4 齐次变换矩阵（origin + xDir/yDir/zDir 三个正交单位轴 + scale）
- 与 Pose(欧拉角) 相比：无万向锁、运算稳定、rebuildFrame() 施密特正交化自愈
- 核心 API 在 Math3D：mathEulerToFrame/mathFrameToEuler 互转；world<->local 点/矢量/坐标系变换
- 业务场景：①用户坐标系下多道焊缝偏移(MultiPathUtils) ②工作角/前进角偏移(OffsetAngle) ③三点定位点位搬移(MathOffsetUtils) ④几何求交(MathIntersection, 圆用 RFrame 描述) 
- 已生成文档：learning/WeldingTools/RFrame坐标系类说明.md

## GenerateTrajectoryTest NPE 诊断
- 现象：本地 IDE 直接跑 GenerateTrajectoryTest.main 报 NPE
- 根因（已本地复现，非入参问题）：SDK `PoseUtils` 的 `@Inject private static ServiceBuilder serviceBuilder` 靠 OSGi 容器 Guice 注入；本地纯 JVM 未注入，`newPose()` → `valueFactory()` → `serviceBuilder.get(...)` NPE（PoseUtils.java:32）
- 复现堆栈：PoseUtils.valueFactory → PoseUtils.newPose → GenerateTrajectoryTest.main:13
- 结论：这些测试类只能在机器人/ELISIM 运行时环境跑，无法脱离 OSGi 本地运行
- 可行本地方案：反射注入 mock ServiceBuilder + 自实现 ValueFactory/Pose/Position/Rotation（接口很小，约 400 行）
- SDK 源码位置：~/.m2/repository/cn/elibot/elibot-plugin-api/1.2.15.0/elibot-plugin-api-1.2.15.0-sources.jar

## 直线节点数据/脚本生成机制
- 直线节点 WeldLinearTaskNodeContribution 无自己的 generateScript，继承自 WeldCommandAbstract.generateScript（WeldCommandAbstract.java:229，只输出 welder.arcOn() + baseCommands）
- 点位数据存 WeldLinearTaskNodeAbstract.java:30-31：linearMovePoseKey(Pose) / linearMoveJointKey(JointPositions)，UI 示教 setLinearPoint()/setLinearMovePose() 写入
- 真正的 movel 指令由父节点 WeldStartTaskNodeContribution 组装：generateScript:150 → createCommand:190 → createTrajectoryManager(喂 TrajectoryManager) + setLinearCommands:203
- setLinearCommands：有摆动时用 TrajectoryManager 插值离散点生成 MoveP/L/CCommand 按 taskPointId 注入；无摆动走 getBaseCommandList:319 直接取 getLinearMovePose()+travelSpeed+blend+角度偏移构造 MoveLCommand
- scriptWriter.writeChildren() 触发各子节点 generateScript 统一写出
