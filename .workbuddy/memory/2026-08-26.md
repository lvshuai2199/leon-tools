## LeonPro MySQL 建表脚本生成
- 需求：根据 LeonPro_backend 生成数据库创建文件
- 产出：`personal-server/LeonPro_backend/SpringBoot/sql/leonpro_init.sql`（9 张表 + 初始 admin 用户/ROOT 角色）
- 库名依据：dev 用 `leonpro_test`，prod 用 `leonpro`（106.12.12.111，root/leon-sql-pw）
- 生成原则：以实体类字段全集为准（mapper XML 的 resultMap 普遍缺字段），列名优先采用 mapper XML 已有映射（如 sys_users/sys_menus 用 `created_at`，其余用 `create_time`），UUID 主键用 VARCHAR(64)
- 保留的实体类拼写错误（改了会断后端）：`sys_role_menu.rold_id`、`extern_accounts.prifit_amount`
- 发现的后端遗留问题（未改，提醒用户）：
  - `MybatisPlusConfig` 的 `@MapperScan("scan.your.mapper.package")` 是占位符
  - `SysMenusMapper.xml` resultMap 缺 6 字段且 id/parent_id jdbcType=INTEGER 与实体 String 矛盾
